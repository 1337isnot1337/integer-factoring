# A primary-character code bounds every unprojected tensor length

For the literal three-letter `theta=4` fused crossing, every decomposition
of its `m`th tensor-power crossing into the full unprojected coefficient
span has rank-sum cost at least `3^(3m/2)`. Thus its balanced parameter is
at least `3/4`, above the required `1/sqrt(2)`, for every positive integer
`m`. This includes arbitrary coefficient recombinations over every field
extension of the fixed `F16` representation. It does not include entrywise
scalar projection or physical type restrictions.

The proof converts a small primary decomposition into a weighted linear
code, then tensorizes that code's distance. No enumeration over tensor
lengths, degrees or field sizes is required. The factoring score remains
`1/2`.

## 1. Six primary characters

Use `T_i`, the two flattened coefficient matrices `F_i,B_i`, and the
literal seed from
[the binary coefficient-envelope note](fused-scalar-projection-envelope.md).
Let `W=span(T_0,T_1,T_2)` over `F16`. The opposite-cut matrices `B_i`
have an explicitly checked simultaneous primary decomposition with the
following dimensions and characters. Field entries use the existing
integer encoding of `F16`; the three character columns correspond to
`B_0,B_1,B_2`.

| Block | Dimension `d_j` | Character `(ell_j0,ell_j1,ell_j2)` |
|---:|---:|---|
| 0 | 1 | `(0,0,1)` |
| 1 | 2 | `(0,12,13)` |
| 2 | 1 | `(1,0,0)` |
| 3 | 1 | `(7,5,3)` |
| 4 | 2 | `(11,0,10)` |
| 5 | 2 | `(12,13,0)` |

On each block,

```math
B_i=\ell_{ji}I+N_{ji},\qquad N_{ji}N_{jk}=0
\quad\text{for all }i,k.
```

The checker retains a literal nine-column basis, verifies its inverse,
checks every off-block entry, and checks all 54 radical pair products.
In particular, the two-dimensional blocks need not be semisimple; their
nilpotent terms are retained. All identities persist under field extension.

For a coefficient vector `a` in `K^3`, define the character word

```math
G(a)_j=\sum_{i=0}^2\ell_{ji}a_i,
\qquad C=G(K^3)\subset K^6.
```

Give coordinate `j` weight `d_j`. The weighted minimum distance of `C`
is exactly three, over every extension `K` of `F16`. To prove the lower
bound, take any support `J` of total weight less than three. The character
rows outside `J` have rank three. There are only ten such supports, and
the checker verifies all ten ranks. A word supported in `J` must therefore
have `a=0`. These are field-extension-stable rank certificates, rather
than a finite sampling of coefficient vectors. The vector `(1,15,9)`
attains weight three, with word `(9,0,1,14,0,0)`.

## 2. Tensorized distance gives an operator-rank bound

Repeat character coordinate `j` exactly `d_j` times. This embeds `C` as
an ordinary length-nine code of minimum Hamming distance three. The
minimum distance of its `m`th tensor code is at least `3^m`.

For completeness, if a nonzero matrix belongs to `C tensor D`, choose
a nonzero row. That row has at least `distance(D)` nonzero entries. Each
corresponding column is a nonzero word of `C`, with at least
`distance(C)` nonzero entries. Hence the matrix has at least the product
of the two distances nonzero entries. Induction proves the tensor claim.

The character map `G` is injective. Therefore a nonzero

```math
X\in W^{\otimes m}
```

has a nonzero tensor character word in `C^(tensor m)`. On a primary block
indexed by `j_1,...,j_m`, the operator for `X` has the corresponding
character value as its scalar part. The remaining terms belong to the
nilpotent ideal generated by the `m` square-zero block radicals. That
ideal's `(m+1)`st power is zero: every product of `m+1` generators repeats
one tensor position and vanishes. A nonzero scalar part thus makes the
whole block invertible by a finite geometric series.

Each such block contributes its entire dimension `product_k d_(j_k)`
to rank. The replicated code's Hamming weight is exactly the sum of
these block dimensions. Consequently

```math
\operatorname{rank}_C X\ge3^m
\qquad\text{for every nonzero }X\in W^{\otimes m}.
```

## 3. Crossing decomposition cost and the remaining escape routes

Let `sum_s X_s=E_(3^m)`, with every nonzero `X_s` in the stated span.
The first flattening of the crossing has rank `9^m`, so
`sum_s r_R(X_s)>=9^m`. Each first-cut rank is at most `9^m`, whence
`sqrt(r_R)>=r_R/3^m`. Combining this with the opposite-cut bound gives

```math
\sum_s\sqrt{r_R(X_s)r_C(X_s)}
\ge3^{m/2}\sum_s\sqrt{r_R(X_s)}
\ge3^{3m/2}.
```

The finite-block parameter is `log(S)/(2 log(3^m))`, so it is at least
`3/4`. This conclusion permits any number of summands and arbitrary
linear combinations, not only the coefficients of a chosen polynomial.

```sh
make verify-fused-primary-code
```

The ordinary proof is supported by
[`check_fused_primary_code.py`](../tools/check_fused_primary_code.py)
and [`fused-primary-code.json`](../evidence/fused-primary-code.json).
The finite algebra checks verify the hypotheses of the all-length argument;
they are not independent review or a Lean proof.

Entrywise binary projection need not commute with the nonbinary primary
basis change. Thus this theorem cannot be applied to the binary projected
envelope without a separate argument. Physical type projection can also
change the relevant blocks and ranks. Those operations remain possible
escape routes, as do other local crossings.
