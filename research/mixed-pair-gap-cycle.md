# Mixed-pair rows on a 40-bit cycle

**Status.** Exact finite certificate on one fixed 40-bit input. No uniform
smoothness, first-hit, rank-window, or stronger factoring theorem is proved.
The complete saving exponent remains **1/2**.

This continues [target orders and mixed rows](target-order-mixed-rows.md),
where exponent-one pair rows form complete relation bases in three small
groups, and the [pooled-rank diagnostic](clustered-hits-and-pooled-rank.md).
The question here is whether the pair mechanism survives at the actual
asymptotic smoothness cutoff, not only in tiny class groups.

## Construction

Take

\[
 N=1000036000099=1000003\cdot 1000033,\qquad D=-N,
\]

and cutoff `Y=177`. The reduced forms of the cyclic subgroup generated by the
prime form `5` form a complete cycle of order

\[
 h=198850.
\]

All `22` split primes through `Y` lie in this cycle:

\[
 5,7,19,37,47,53,59,73,83,97,101,103,107,109,113,127,131,137,151,163,167,173.
\]

For an unordered pair `p<=q` of targets and exponent `k=1,2,3`, form the
class of `(pq)^k`. If its reduced leading coefficient `A<=H=577360` factors
over the split primes through `Y`, the exact decoder gives a signed word `v`
with `(pq)^k=\prod r^{v_r}`. The integer relation is

\[
 k(e_p+e_q)-v.
\]

No order row is used.

## Single-hit extension lemma

The finite scan is not the main structural point. The following elementary
observation separates the rank problem from the first-hit problem.

**Lemma.** Let `B` be a target set with a relation matrix `R_B` of full rank
`|B|`. Let `p_1,...,p_t` be additional targets, and suppose for each `i`
there is one relation

\[
 r_i=k_i e_{p_i}+w_i,\qquad k_i\ne0,
\]

whose support `w_i` lies in `B`. Then the `|B|+t` rows obtained from `R_B`
by adding zero columns at the new targets, together with the `r_i`, have full
rank `|B|+t` and determinant

\[
 \left(\prod_i k_i\right)\det R_B
\]

up to sign.

**Proof.** Order the new target columns last. The base rows have zero entries
there; row `r_i` has a nonzero entry only in its own new column among those
columns. The matrix is block triangular after that ordering, and the new
block is diagonal with entries `k_i`. \(\square\)

A relation row for `p_i` comes from one smooth pair `(p_i q_i)^{k_i}` with
`q_i` in `B`. Thus **one smooth pair hit per gap target** extends a full-rank
base matrix; no rank condition on the gap target and no interaction among the
gap targets is needed. The first-hit exponent is the only new window cost.

The same proof allows a tree rather than a star. Suppose the smooth-pair graph
on `B union P` has a spanning forest in which every tree contains a root in
`B`, and every edge word is supported on `B`. Orient each tree toward its
root and order the new targets by distance from the root. The edge row for a
child has a nonzero coefficient on that child and only earlier/base columns,
so the rows are block triangular over the full-rank base matrix. Hence the
rows have full rank and determinant `(prod_e k_e) det R_B`. **One smooth pair
hit per tree edge suffices; a target need not have a direct hit to the base.**
The obligation is now a rooted-forest connectivity statement for the
smooth-pair graph.

For the 40-bit cycle, the base alone has rank `22` at window `3`, with selected
determinant

\[
 200440800=1008h.
\]

The ten hits listed above add one diagonal row each. The combined `32`-column
matrix has rank `32` and determinant

\[
 200440800\cdot(2\cdot2\cdot2\cdot1\cdot1\cdot3\cdot1\cdot1\cdot2\cdot2)
 =19242316800=96768h.
\]

All `32` rows replay exactly, and using the determinant as annihilator the
two-part extractor returns the factor `1000003`. This simultaneous extension
holds at window `3`; several individual target sets are already full at
window `2`, so the combined window is not claimed to be minimal.

## Pure-order control

A diagonal control shows that the pair-row and smooth-row constructions are
not needed for **extraction** in this fixed instance. For each of the `32`
targets, the row `ord(p)e_p` is a valid relation: `p` raised to its class
order is principal. The checker asserts all `32` diagonal rows replay, forms
the diagonal determinant

\[
 \prod_p \operatorname{ord}(p)
\]

of bit length `434`, and runs the same two-part extractor. It returns
`1000003`.

This is not a competing factoring method. The orders are obtained here from
the enumerated cycle and its discrete logs; the class-group enumeration is the
dominant cost. A generic order computation by baby-step giant-step costs about
`sqrt(h)` group operations, and `h` is about `D^{1/2}` in the usual class-group
regime, so this route is about `D^{1/4}` before any extraction. The pair-row
certificate avoids global order information but pays the first-hit search.
Neither is a complete-bound improvement. The control is recorded so the
finite pair result is not mistaken for an extraction necessity.

## Isolated-column repair

Pair rows can leave a target column completely zero. This is a supply gap,
not necessarily a determinant obstruction. The following elementary repair
separates the two.

**Lemma.** Let `R` be a set of relation rows on target set `V`, and let
`I` be the set of columns that are zero in every row of `R`. Suppose `M`
annihilates every target class. Adjoin the diagonal rows `M e_i` for
`i in I`. Then the rank increases by `|I|` and the determinant is
multiplied by `M^{|I|}`.

**Proof.** The columns in `I` are zero in all original rows, while each new
row is supported only on one column of `I`. The column spaces are therefore
independent. \(\square\)

The common annihilator can be a multiple of the cycle order; individual
orders and discrete logs are not required. On all split primes through
`500` (`50` targets), the window-`2` pair rows give `104` distinct rows of
rank `49`. The sole zero column is `229`. Adjoining `h e_229` raises the rank
to `50`; a selected minor has `69` bits and is a multiple of `h`, and the
extractor returns `1000003`.

This is the finite complementarity suggested by the rank sweep: isolated
targets are exactly those needing an external row, and a single common
annihilator supplies it without a pair hit. It does not improve the complete
bound. Constructing the annihilator by baby-step giant-step costs about
`sqrt(h)` group operations, and if many targets are isolated their order rows
add factors of `M` to the determinant. A density-supplied row at lower cost
would be the useful hybrid; the lemma only says what to do with the missing
columns.

## Edge-only collective basis

The tree lemma still uses a separate full-rank base matrix. On the same
40-bit target set, the pair rows alone can span a full-rank relation matrix,
and they do so one window earlier than the separate base matrix. Take all
`32` vertices (the `22` base primes and the ten gap targets) and all nonzero
pair rows at exponent at most `2`. At window `1` there are `9` distinct rows
of rank `9`; at window `2` there are `53` distinct rows of rank `32`.

A selected `32 x 32` minor at window `2` has determinant

\[
 1628979200=8192h.
\]

That minor is not primitive. The full row lattice generated by all
window-`2` pair rows has covolume

\[
 3181600=16h
\]

of only `22` bits. An Hermite-normal-form basis of the row lattice replays
exactly, and its determinant annihilator extracts `1000003`. Since the target
set contains `5` and generates the order-`h` cycle, the full relation kernel
has index `h`; the pair-row lattice therefore has index `16` in that kernel.
The quotient is a `2`-group, and the selected `8192h` minor is
`512*16h`, not the lattice covolume.

At window `3` the index drops to exactly `h`. Since the target set contains
`5` and generates the order-`h` cycle, the full relation kernel also has
index `h`; hence the window-`3` pair rows generate the **entire** relation
kernel of `Z^32 -> <5>`. The window-`2` pair rows are already a sublattice
of index `16`; the only missing part is a `2`-group.

The `16`-defect is saturated by just four exponent-`3` base-gap rows:

\[
 (53,25169),\quad (59,43987),\quad (101,96749),\quad (103,1289).
\]

Adding them successively gives indices `8h`, `4h`, `2h`, `h`. The mod-`2`
row ranks are `27` at window `2` and `31` at window `3`; each repair row
raises the rank by one. Since one additional row can raise the mod-`2` rank
by at most one, **four rows are necessary**, and the displayed four achieve
the full kernel. Thus the window-`2` rows plus these four rows generate the
full kernel; no other window-`3` row is needed.

The checker also implements a targeted search: after the window-`2` rows, it
scans only base-gap pairs at exponent `3`, adds a candidate only when it
raises the mod-`2` rank, and stops when the index reaches `h`. It finds the
same four rows after `112` base-gap candidates, instead of testing all `528`
pairs at exponent `3`. This is a finite search-cost reduction; it is not a
uniform bound on the defect size or on the number of base-gap candidates
needed for other inputs.

The window-`2` certificate uses no base relation row, no order row, and no
exponent-`3` row.

This is not a pair-endpoint connectivity effect. At window `2` the
pair-endpoint graph has root component `1`: no nonzero pair row touches the
chosen base root. At window `3` the pair-endpoint graph becomes connected
and non-bipartite, but the matrix is already full rank at window `2`.

The weighted row supports behave differently. At window `2` every one of
the `32` vertices occurs in some selected row, and the `2`-section of the
weighted supports is connected. The word terms, not the pair endpoints
alone, supply this coverage and connectivity. This is only a finite
support diagnostic, not a rank theorem: a connected support hypergraph
does not in general force an incidence matrix to have full rank.

There is a sharper block-rank description. Restrict the window-`2` pair
rows to the `22` base columns: their rank is `22`. Restrict them to the
ten gap columns: their rank is `10`. The two block ranks sum to the full
rank `32`. The base-base pair rows alone have rank only `20`; rows
involving gap targets repair the two missing base directions while also
supplying all ten gap directions. Thus gap rows can compensate for a
deficient base block, unlike the single-hit lemma which needs a full base
matrix before extension. This is a finite direct-sum rank fact, not a
uniform repair theorem. A uniform version would need enough target rows
to repair the base defect and would still pay their first-hit search
cost.

## What is and is not proved

- The checker reconstructs the complete cycle, all pair rows, the exhaustive
  gap scan, the rank profiles, every selected row identity, the maximal
  minors, the single-hit extension matrix, the window-2 edge-only basis, and
  the extraction. It does not rely on saved smooth flags.
- The determinant is a multiple of the **cycle order** `198850`, the subgroup
  generated by the factor base; the ambient class group may be larger. This is
  enough for the extractor because `5` is in the factor base and the rows
  annihilate that subgroup.
- The ten targets are genuine gap targets for the current sufficient
  windows: their indices exceed `D^{1/4}`, so the small-index density theorem
  does not cover them, and their orders exceed the exponent windows.
- The tree extension and the isolated-column repair are proved; the
  edge-only bases are finite arithmetic facts. HNF checks index `16h` at
  window `2` and index `h` at window `3`; the latter makes the pair rows a
  complete relation basis for the cycle subgroup. Four exponent-`3` base-gap
  rows saturate the window-`2` `2`-defect, the mod-`2` rank gap proves four
  is minimal, and a targeted base-gap search finds them after `112`
  candidates. No uniform rooted-forest,
  isolated-target supply, lattice-index, saturation-count, or weighted-pair
  rank theorem is supplied.
- The base alone and the pure-order diagonal control already yield the
  factor in this fixed instance; the gap-target and pair rows test coverage of
  additional target columns, not extraction necessity.
- The certificate does not show that first hits can be found faster than
  scanning candidate pairs. That search is the next cost bottleneck; the
  lemma reduces rank and interaction, not the first-hit search.
- The scan is exhaustive only up to `100000` for this one input. It does not
  prove that a first hit exists for every target, nor that the first-hit
  exponent is uniformly small. Those are now the precise open obligations.
- The class-group enumeration used by the checker is exponential in the input
  size. The certificate is not a factoring algorithm and does not change the
  complete bound.
