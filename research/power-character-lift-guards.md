# Path C: character lifts explain a rank stall exactly

**Result.** An elementary integer-lift bound predicts the observed
generator-seven rank stall exactly, and certifies long rough gaps in the
generator-five walk. A complementary lemma shows that this particular
obstruction disappears under the repository's existing constant-bias
factor-base contract at sufficiently large input size. Neither lemma
proves a uniform smoothness or rank-window theorem. The complete score
remains **1/2**.

This is an ordinary-proof continuation of the
[saved-hit and pooled-rank audit](clustered-hits-and-pooled-rank.md),
registered in [Discussion 51](https://github.com/1337isnot1337/integer-factoring/discussions/51#discussioncomment-19341133).
It reuses exactly those rows and cycles, with no new arithmetic orbit,
cutoff, fitted constant, or class composition in the new postprocessing.

## 1. Lifted characters constrain both rows and hit phases

Suppose the factor-base classes lie in a cyclic group generated by `g`
of known order `h`, and `g_q=g^{J_q}`. It is enough that this cyclic
subgroup contains the base; no assertion about the entire class group
is needed for this lemma. Fix an integer multiplier `a` and integer lifts

\[
 z_q\equiv aJ_q\pmod h.
\]

Every genuine integer relation `r` has `r.z` in `h Z`. For reduced
smooth leading norms bounded by `H`, define the exact finite budget

\[
 B_z(H)=\max\left\{\sum_q e_q|z_q|:
                e_q\in\mathbb Z_{\ge0},\ \prod_q q^{e_q}\le H\right\}.
\]

This is a definition, not a claim that the general maximum can be
computed in polynomial time. The small finite base below permits an
exhaustive 79-element support check.

For the exact oriented norm word `v`, `prod q^{|v_q|}<=H`, so
`|v.z|<=B_z(H)`. A row at target `p`, exponent `k>=0`, has
`r=k e_p-v`, hence

\[
 r.z\in h\mathbb Z,\qquad |r.z|\le k|z_p|+B_z(H).
\]

Two consequences follow without a statistical assumption:

1. If **`k|z_p|+B_z(H)<h`**, then `r.z=0`. All smooth rows in that
   interval lie in the same proper rational hyperplane when `z!=0`.
2. A smooth hit requires **`dist(k z_p,h Z)<=B_z(H)`**. Thus a slow
   character can force long empty windows, even after adjacent hit runs
   have been collapsed to entries.

There is also a useful bound without the cyclic-character hypothesis:
for any real nonzero vector `z`, if `k|z_p|>B_z(H)`, then every decoded
row has `r.z!=0`. This identifies directions in which a future hit
escapes a given row span. It does not guarantee when a hit occurs.

## 2. Exact explanation of the saved data

Use `N=1000036000099`, base `(5,7,19)`, `H=577360`, and
`h=198850`. The previously checked indices are `J=(1,66509,43240)`.
The primitive cross product of the first two independent rows in each
direction gives the following normal. Both satisfy `z=z_5 J mod h`.

| Target | Normal z | Exact B_z(H) | Maximizing unsigned norm | First possible escape k | Actual first escape k |
| --- | --- | ---: | --- | ---: | ---: |
| 5 | (-9,-2031,8540) | 34160 | 19^4 | 18299 | 19968 |
| 7 | (-15861,1,4010) | 126888 | 5^8 | 71962 | 71962 |

The table's possible-escape endpoint is
`ceil((h-B_z(H))/|z_p|)`, using the strict inequality in the guard.
For target seven, the first rank-three row is exactly

\[
 r=(-8,71962,0),\qquad r.z=198850.
\]

Its decoded word is `v=(8,0,0)`, with norm `5^8=390625`. This attains
the budget, so the theoretical endpoint is sharp on this actual input.
All earlier saved smooth rows are forced into the plane; treating them
as independent samples cannot explain this rank history.

For target five, the modular hit-phase guard forbids **130529** of the
198850 phases and contains **14504 consecutive forced-rough positions**.
The measured longest rough run is 17939. This is a macroscopic arithmetic
correlation, beyond the previously observed identical adjacent rows.
For target seven its budget exceeds `h/2`, so the modular guard forbids
no phases; the rank guard remains informative. Hit scarcity and rank
scarcity therefore have different certificates even on the same cycle.

These normals were obtained from the existing first two rows, not guessed
before seeing them. The guards are exact mathematical explanations of
that finite history, not a new predeclared speedup or an all-input family.
Knowing `h` and the indices is part of these diagnostic certificates;
their fast acquisition is not assumed in a factoring algorithm.

## 3. A sufficiently rich biased base defeats this obstruction

Here is a useful limit on extrapolating the three-prime experiment.

**Lemma.** Let a probability distribution on the base generators and their
inverses have absolute character bias at most `1/4` for a nonprincipal
character `chi`. Suppose each prime in its support satisfies `q^6<=H`.
Write `chi(g_q)=exp(2 pi i z_q/h)` with any integer lifts. Then
**`B_z(H)>=h`**.

*Proof.* If `B_z(H)<h`, the allowable norm `q^6` implies
`6|z_q|<=B_z(H)<h` for every support prime. Thus
`Re chi(g_q)>cos(pi/3)=1/2`, also for the inverse orientation. The
distribution's mean character value has real part greater than `1/2`,
contradicting absolute bias at most `1/4`. This proves the claim.

The repository's [polylogarithmic prime-form construction](polylog-prime-form-generators.md)
supplies constant-bias support of polynomially bounded prime norms under
its pinned analytic and effective-estimate contract. With `H` of reduced
form size, the sixth-power condition holds for sufficiently large inputs.
Hence **this particular lift-budget rank guard is then vacuous** for
every nonprincipal character: `k|z_p|+B_z(H)<h` cannot hold for `k>=0`.
This is a conditional deduction from that existing contract, not a new
verification of its external analytic input.

Both finite normals above instead have `6|z_q|<h` on every base prime.
Any distribution on just those three generators and their inverses
therefore has character mean real part greater than `1/2`. This base
cannot satisfy the constant-bias hypothesis in either character.
Its small experimental cutoff must not be confused with a uniformly
valid analytic factor base.

Removing this guard supplies no smooth hit, no moment estimate, and no
rank-generation rate. A normal to a partial relation span need not be
an integer lift of a genuine class character. Other rank stalls remain
possible. The next useful theorem must exploit the richer arithmetic
base constructively, rather than assume that a vanished obstruction
proves random-walk behavior.

## 4. Reproduction

The [integer checker](../tools/check_power_character_lifts.py) recomputes
the two normals, their congruences, all 79 unsigned supports, exact budgets,
forced rank intervals, and modular forbidden phases against the saved
full flags. It uses no floating point. The prerequisite rechecks the
original group/order/row/factor certificates; those verification operations
are separate from the discovery composition cap.

```sh
make verify-power-character-lifts
```

The [receipt](../evidence/power-character-lifts.json) pins the three
upstream data files. To regenerate this integer postprocessing only:

```sh
python3 tools/check_power_character_lifts.py --output evidence/power-character-lifts.json
```

The small-bias lemma is an ordinary argument above, not a Lean theorem or
a finite-test inference. No independent mathematical review is claimed.
