# Joint polynomial filters on a global syndrome alphabet

## Constructive interface

This construction assigns an independent polynomial \(f_b\) to every syndrome
\(b\in(\mathbf Z/2)^c\). It extends the single-support family \(1+R g_b\) from
[`boolean-multiplier-automata.md`](boolean-multiplier-automata.md). The interface
decides exact coefficient feasibility and produces all endpoint colors and
all transformed polynomials. The weighted target walk described below is a
search heuristic; it is not a global optimizer or a pressure-floor theorem.

Let \(h_i\) be the binary column assigned to physical mode \(i\), and let
\(b(k)=\sum_i h_i k_i\). Set

\[
 f_k(x)=f_{b(k)}(x).
\]

Every syndrome polynomial must have \(f_b(1)\ne0\). Some column groups may be
empty; zero columns are spectators. All actual physical mode assignments
remain part of a candidate.

## 1. Exact transform in a fixed number of parity states

For each nonzero column type \(h\), let \(z_h\) be the parity of occupations
in that group. Put

\[
 W_{z,b}(Y)=[e_b]\prod_{h:z_h=1}\bigl(1+Y(1+e_h)\bigr).
\]

The augmentation ideal is generated by \(c\) commuting square-zero elements,
so its \((c+1)\)-st power is zero. This proves that the displayed polynomial
has degree at most \(c\). With \(X=x^m\), the original
finite-difference transform is exactly

\[
 \beta_k(x)=X^{|k|}\sum_b f_b(x)W_{z(k),b}(X^{-1}).       \tag{1}
\]

The identity follows by expanding the product of
\(X+1+e_{h_i}\) over occupied physical modes. Equal column types reduce to
their occupation parity because \((1+e_h)^2=0\) in characteristic two.

To permit fractional degrees in units of \(m\), write \(X=U^s\), where \(s\)
is a positive integer and a compatible ramification makes \(U\) a monomial
in \(x\). Define polynomial outputs

\[
 \delta_z(U)=\sum_b A_{z,b}(U)f_b(U),\qquad
 A_{z,b}(U)=U^{sc}W_{z,b}(U^{-s}).                       \tag{2}
\]

Then

\[
 \beta_k=U^{s(|k|-c)}\delta_{z(k)}(U).                  \tag{3}
\]

Even when the displayed monomial exponent is negative, (3) is an ordinary
polynomial: the right side is exactly the original subset transform. The
required divisibility is automatic. At the endpoint,
\(\delta_z(1)=f_{\sum_h h z_h}(1)\), so every output is nonzero.

For rank three with all seven nonzero column types, (2) has eight independent
input polynomials and 128 output states. The number of physical modes can
grow without enlarging that coefficient system.

## 2. Exact simultaneous endpoint feasibility

Choose nonnegative degree caps \(D_b\) and output order targets \(T_z\). The
unknown coefficients are

\[
 [U^j]f_b,\qquad 0\le j\le D_b,
\]

so there are \(\sum_b(D_b+1)\) scalar unknowns. Requiring every coefficient of
\(\delta_z\) below \(T_z\) to vanish gives a binary homogeneous linear system
\(Cv=0\). Let \(e_b\) be the binary row functional evaluating \(f_b(1)\).

There is a solution over a characteristic-two extension with every endpoint
nonzero **if and only if** no \(e_b\) lies in the row space of \(C\). Necessity
is immediate. For sufficiency, each endpoint is a nonzero functional on the
kernel, so its vanishing set is a proper hyperplane. Over a field of size
\(Q>2^c\), the union of the \(2^c\) hyperplanes cannot cover the kernel.
The implementation constructs such a vector over \(\mathbf F_{2^{c+1}}\).

In particular, rank three uses \(\mathbf F_{16}\). Fixing every endpoint to 1
would discard valid profiles. An exact rank-two control has column types
\((1,2,3)\), spacing 1, caps \((0,1,2,0)\), and order targets

\[
 (2,2,2,3,2,2,2,3).
\]

These targets admit

\[
 f_0=1,\quad f_1=1+\omega U,\quad
 f_2=1+\omega U+U^2,\quad f_3=1,
\]

whose endpoints are \((1,1+\omega,\omega,1)\), all nonzero. The same system
with every endpoint equal to 1 is inconsistent. The checker retains the
literal polynomial outputs as a negative control for that extra restriction.

## 3. Incremental weighted target walks

Adding one target coefficient is one binary row insertion. Maintain a row
echelon basis for the constraints and the reduced endpoint functionals. A
new constraint is accepted precisely when none of those endpoint remainders
becomes zero. A rejected coefficient can remain blocked: adding more
constraints cannot restore a lost endpoint functional.

The search starts with zero order targets on every output. It therefore
allows a candidate to lose order on rare states. At fixed \(\tau=nt\), an
increase of one output order has a zero-cost benefit proportional to
\(q_z e^{-2\tau T_z/s}\). The target walk uses this priority, optionally with
a recorded perturbation to explore alternate feasible flags. All feasibility
decisions and the final coefficient witness are exact.

A common monomial dividing every \(f_b\) is removed from the complete input
and output vectors. This subtracts the same order from every output and the
same degree from every input. The reciprocal scalar changes in the two cost
factors cancel exactly. Endpoint values remain unchanged.

### Releasing a coefficient-space direction

A marginal target walk can become trapped after imposing too many baseline
order constraints. The implementation also constructs exact feasible
weakenings. For an echelon-basis constraint row, solve for a dual coefficient
vector that evaluates to 1 on that row and 0 on the other basis rows. In each
output, retain only the prefix of coefficient constraints that annihilate the
dual vector. The resulting row space lies in a proper hyperplane of the old
row space, so it releases at least one coefficient-space direction. All
endpoints remain feasible because constraints were only removed.

One can then force a higher target on another output and run the exact
feasibility check before completing the target walk. This step can recover
profiles missed by the original ordering. An explicit uniform-bias control
starts with \(f_0=1+X^3+X^4\) and all other \(f_b=1\), on three independent
parity groups. Writing \(q=e^{-2\tau}\), its relative cost is

\[
 \frac{7+q^4}{8}\,\frac{7+q^{-4}}8>1.
\]

A basis release and a forced output target instead produce
\(f_0=1+X^2+X^4\), with relative cost

\[
 \frac{4+3q^4+q^{-1}}8\,\frac{7+q^{-4}}8<1
       \quad\text{at }q=9/10.
\]

The checker compares these costs as exact rationals. This is an algorithmic
control for the search heuristic, not a physical factoring candidate.

## 4. Complete physical cost

Let \(q_z\) be the charged parity-state distribution, and let \(p_b\) be the
uncharged syndrome distribution, computed from the actual physical modes.
If \(B_z=\operatorname{ord}_0\delta_z\) and
\(D_b=\deg f_b\) after common-monomial normalization, the full relative cost is

\[
 \left(\sum_z q_z e^{-2\tau(B_z/s-c)}\right)
 \left(\sum_b p_b e^{2\tau D_b/s}\right).               \tag{4}
\]

Every infinity degree is included. Charged and uncharged probabilities are
kept separate. The total pressure adds the Gaussian pressure of the entire
physical system, including any spectators.

For a fixed synthesized profile, both factors in (4) depend on a nonzero
column group only through its two parity biases. These are the products of
the corresponding uncharged and charged \(\tanh\) factors. This permits
searches over the assignment of actual modes to column classes without
re-synthesizing the polynomials. Every accepted assignment still specifies
the exact mode-energy list in each class.

## 5. Arbitrarily fine ramification by residue compression

The matrix in (2) has shifts divisible by \(s\). Write each input polynomial
as \(\sum_{r=0}^{s-1}U^r F_{b,r}(U^s)\). The coefficient constraints separate
into residue classes, with local bounds

\[
 D_{b,r}=\left\lfloor\frac{D_b-r}{s}\right\rfloor,
 \qquad
 T_{z,r}=\max\!\left(0,\left\lceil\frac{T_z-r}{s}\right\rceil\right).
\]

A local degree of \(-1\) means that the coordinate is absent in that residue.
Each local system is the spacing-one version of (2). The endpoint image of
the full coefficient kernel is the sum of the local endpoint images. In
particular, an individual residue need not support all nonzero endpoints.
The combined image must be tested against the coordinate hyperplanes.

The local bounds change only at a degree cut \(D_b\bmod s+1\) or an order cut
\(T_z\bmod s\). There are therefore at most
\(2^c+2^{\#\text{column types}}+1\) distinct residue patterns, independent of
\(s\). One representative of each pattern suffices for endpoint feasibility
and for a sparse polynomial lift. Rank three with seven column types needs
at most 137 patterns.

The compressed constructor has literal controls at spacings 127, 257, and
65,537. In the last control, the original coefficient system has 196,615
unknowns, while every local residue system has at most seven. The full
physical-state polynomial identity is still checked exactly.
