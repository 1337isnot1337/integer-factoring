# Polynomial factor extraction from a class-group annihilator

Let `N>1` be odd and have at least two distinct prime factors. Suppose
`g_1,...,g_m` generate the full proper class group of discriminant `-4N`,
and a nonzero integer `E` annihilates every generator. A proper factor
of `N` can then be found deterministically using

$$O\bigl(m\,\mathrm{bits}(E)+m b^2\bigr)\tag{1}$$

class-group operations, where `b=bits(N)`. With the
[polynomial-bit ideal implementation](direct-discriminant-short-norms.md),
this is polynomial in `m`, `b`, and the written bit length of `E`.

The algorithm neither factors `E` nor computes a full two-torsion
basis. It stops when a useful ambiguous class appears. The
classification at discriminant `-4N` shows that at most one cyclic
direction needs to be retained before that happens. This removes
the `2^(r/2)` generic rank cost in the earlier
[full-basis algorithm](arithmetic-torsion-extraction.md).

The remaining open work is finding the short smooth norms that supply
the relation matrix and hence `E`. This result does not improve the
complete factoring score by itself.

## 1. The exceptional subgroup has order at most two

The [direct-discriminant classification](direct-discriminant-short-norms.md)
proves that a primitive reduced ambiguous form at discriminant `-4N`
gives a proper factor by explicit gcd tests, with just these exceptions:

* The principal form `(1,0,N)`.
* When `N=1 mod 4`, the form `tau=(2,2,(N+1)/2)`.

The exceptional classes form a subgroup `T` of order at most two.
If `N` has two distinct prime factors, write it as a nontrivial
coprime product `N=u v`. The reduced form
`(min(u,v),0,max(u,v))` is an ambiguous class outside `T`. This is an
existence argument; the algorithm does not need the unknown factors.

For a nonidentity order-two element, the gcd test therefore rejects
at most one possible class. We use this special fact instead of
computing coordinates in the entire two-torsion subgroup.

## 2. A generic early-exit lemma

Let `H` be a finite abelian two-group generated by supplied elements.
Suppose a test recognizes every useful nonidentity order-two element
and rejects at most one such element, called `tau` when it exists.
Let `2^B` bound the order of every element.

There is a deterministic procedure that finds a useful top whenever
one exists in `H`, using `O(m B^2)` group operations. It retains at
most one cyclic generator.

### Procedure

An element `h` of order `2^k` has top `h^(2^(k-1))`. Repeated squaring
computes its order and top using at most `B` group multiplications.
Process the input generators in order. Maintain either no retained
generator or a retained element `a` of order `2^j`, whose top has
already failed the useful-element test.

For the current candidate `h`:

1. If `h=1`, finish this candidate.
2. Compute its order `2^k` and top `t`. If `t` is useful, return it.
3. If no element is retained, retain `h` and continue to the next
   input generator.
4. Otherwise both tops equal `tau`. If `k>j`, exchange the retained
   element and the candidate, together with their order exponents.
   Now `k<=j`.
5. Replace the candidate by

   $$h\,a^{-2^{j-k}}.\tag{2}$$

   Its top cancels. Return to step 1 with this candidate.

### Correctness and termination

In (2), both elements being multiplied have order `2^k` and top
`tau`, so their product has order dividing `2^(k-1)`. A swap does
not change the subgroup generated by the retained element and the
candidate. Cancellation also preserves that subgroup, because the
old candidate is recovered by multiplying the new candidate by a
power of the retained element.

Consequently, after processing each input, the retained element
generates the subgroup generated by every processed input, unless a
useful top has already been returned. Each cancellation strictly
decreases the candidate's order exponent. If a swap occurs, the new
candidate's exponent is already smaller than its previous exponent,
and cancellation decreases it again. At most `B` cancellations occur
per input.

If the algorithm reaches the end without returning a useful top,
the full group `H` is cyclic or trivial and its order-two subgroup
lies in `{1,tau}`. Thus `H` contains no useful top. This proves both
the positive guarantee and the meaning of a failure return.

Each order calculation and correction requires `O(B)` group
operations, and there are at most `B` corrections per input. This
proves the stated `O(m B^2)` cost. No search in a large binary span
occurs.

### Why individual top powers still do not suffice

In `Z/8 x Z/2`, the two generators `(1,0)` and `(1,1)` have the same
top `(4,0)`. If that top is exceptional, inspecting those two tops
alone fails. The cancellation step returns `(0,1)`, which is useful.
The method preserves the correction needed in the general basis
algorithm while avoiding all irrelevant directions after success.

## 3. Apply the lemma to an arbitrary annihilator

Write

$$|E|=2^s u,\qquad u\text{ odd}.$$

Stripping powers of two finds `u` without factoring the odd part.
The elements `g_i^u` generate the full Sylow two-subgroup: `u` kills
the odd-order component and acts invertibly on the two-part. Binary
powering costs `O(m bits(E))` group operations.

Use the gcd factor test from Section 1 as the useful-top test. A
useful top exists, and all supplied generators span the full class
group, so the generic lemma must return a proper factor.

A completely elementary order bound is enough. A reduced form has
`a<=sqrt(D/3)` and at most `2a+1` possible middle coefficients, where
`D=4N`. The total number of coefficient pairs is less than `4D`.
Thus `B=bits(D)+2=O(b)` bounds every order exponent. The algorithm
does not need the class number, the two-rank, or the factorization of
`D` to compute this bound. Substitution gives (1).

In particular, trial division through an exponential range is no
longer needed to bound the two-rank in this extraction step. Even
factors, primes, and perfect powers are handled separately by the
usual deterministic polynomial-time preprocessing.

## 4. Consequence for the smooth-norm search contract

The [single-target norm construction](direct-discriminant-short-norms.md)
uses a strictly diagonally dominant square relation matrix `A`.
Its determinant is nonzero, and the adjugate identity shows that

$$E=|\det A|$$

annihilates every supplied generator. Saturation of the relation
lattice is unnecessary. The prime-form theorem supplies full
generators at `Delta=-4N`, and its smooth prime factor base can be
included in the same list.

Once the relation rows are supplied, the complete conversion from
those rows to a proper factor therefore has polynomial bit cost in
the matrix dimensions, entry lengths, and `b`. The determinant and
group exponentiation may involve a large written integer, but its
bit length is bounded by the same Hadamard estimate used in the
relation construction.

This isolates the open problem more sharply: locate the guaranteed
primitive smooth represented norms with the prescribed multiplicity
budget. The final torsion extraction does not add an independent
subexponential search term.

## 5. Implementation and exact controls

The implementation is
[early_ambiguous_factor.py](../tools/early_ambiguous_factor.py).
`first_useful_top` is a generic group routine with a supplied useful-top
predicate. `factor_from_annihilator` applies it to `C_(-4N)` using the
polynomial-bit HNF group operations. Neither routine enumerates
classes or determines the group order.

Run:

```sh
python3 tools/check_early_ambiguous_factor.py
```

The [checker](../tools/check_early_ambiguous_factor.py) uses known
product-group coordinates only to validate the black-box output.
It includes independent generators with identical tops, a mandatory
order swap, 128 successive cancellations, odd-order components,
redundant generators, and deliberately oversized annihilators.
Every operation count is checked against a polynomial upper bound,
and the retained cyclic rank never exceeds one.

The actual class-group fixtures enumerate small reduced-form groups
to supply certified generators and an annihilator. That enumeration
is explicitly confined to the checker. Composite targets with
repeated prime factors and prime-power controls distinguish the
success guarantee from its necessary hypothesis. The
[evidence record](../evidence/early-ambiguous-factor.json) reports the
counts and outputs: 303 product-group controls, two-rank as large as
23, 32 actual class-group controls, and 20 successful factoring
targets. The actual class-group cases exercise 11 cancellations and
an order swap. The depth control performs all 128 required
cancellations and correctly reports that its sole nonidentity top
is exceptional.

This is a specialization of the earlier generic group argument to
the small exceptional subgroup in this arithmetic application. No
novelty claim is made for generic abelian-group basis methods.

Substantial OpenAI assistant support was used. No Lean formalization
or stronger complete factoring score is claimed.
