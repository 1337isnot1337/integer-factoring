# Polynomial-time decoding of every grouped boundary entry

## Result

The Boolean [observable-boundary constructor](observable-boundary-constructor.md)
can compute each table entry in polynomial bit time. A slightly larger
transform modulus makes the entire bounded digit box lie inside the
exact decoding region of an LLL-reduced lattice basis.

**Theorem.** Let `N>=2` have `n` bits and let `P>=2`, `P^40<=n`.
For every operand-length class and every divisor-prefix query, there is
a deterministic construction of the same exact Appendix B count with

```math
P^2\lambda<17n,\qquad B_{\rm tab}=1,
\qquad\text{time }n^{O(1)}P\,2^{(P-1)\lambda}
              \le n^{O(1)}2^{17n/P}.                 \tag{1}
```

The polynomial degree is absolute. Every individual boundary-table
entry takes polynomial bit time. The full constructor still writes
all `2^((P-1)lambda)` labels in every row. Uniformly as `P` grows under
the cutoff, its leading top volume remains

```math
P^2\lambda=(12+o(1))n.                              \tag{2}
```

This replaces the previous `2^(kappa^2 w)` search for one entry.
It does not replace the full written table by an uncharged oracle,
and does not establish a new factoring exponent.

## 1. One change in the transform modulus

Retain the observable constructor's exact parameters

```math
\begin{gathered}
h=\text{least power of two at least }P^9,\quad
A=2h,\quad D=A^2/2,\quad T=A^2,\quad t=\log_2D,\\
w=2\left\lceil\frac{n+1}{2(T-A-1)}\right\rceil,
\qquad b=2^w.
\end{gathered}
```

Use the new modulus

```math
m=D\left\lceil\frac{2w+t+A}{D}\right\rceil,
\qquad M=2^m+1,\quad f=m+1.                        \tag{3}
```

The root `omega=2^(m/D)` still satisfies `omega^D=-1 mod M`, so all
principal-root identities, transform inverses, carry checks, and factor
assignment proofs remain valid. The exact convolution bound is only
strengthened. The input radix, supports, carry width `c=w+t`, and
carry bound `K=D(b-1)` are unchanged.

Write `eta=omega^A`. All differences of distinct powers of `eta` are
units in `Z/MZ`, by the geometric identity in the observable note.
Each first-transform gate has at most `A-1` bounded coefficients.
The explicit relay grouping hides a consecutive interval `I` of at
most `A/2` recipient indices from that gate.

## 2. A Euclidean separation bound for the observation lattice

Fix `1<=a<=A-1`. Define the full-rank integer lattice

```math
\Lambda_{a,I}=\left\{v\in\mathbb Z^a:
 \sum_{i=0}^{a-1}v_i\eta^{ij}=0\pmod M
 \text{ for every }j\notin I\right\}.             \tag{4}
```

It contains `M Z^a`. We prove

```math
\lambda_1(\Lambda_{a,I})\ge\sqrt{M/2}.            \tag{5}
```

Suppose that a nonzero coefficient vector `v` in this lattice has
norm less than `sqrt(M/2)`. Regard it as an integer polynomial of
degree at most `A-2`. We apply the cyclotomic induction from the
Boolean uniqueness proof, now keeping Euclidean norms.

At a stage `L=A,A/2,...,4`, write

```math
v(X)=S_{A/L}(X^L)g(X),\qquad \deg g\le L-2,
\qquad\|g\|_2\le\|v\|_2.                         \tag{6}
```

At least `L/4` primitive `L`th recipients are outside `I`: these
recipients have spacing `2A/L`, so a consecutive interval of length
at most `A/2` contains at most half of them. The geometric prefactor
in (6) is the unit `A/L` there. Put `q=L/2` and fold `g` modulo
`X^q+1`. Its remainder `r` satisfies

```math
\|r\|_2\le\sqrt2\,\|g\|_2<\sqrt M.              \tag{7}
```

If `r` is nonzero, evaluation at `q/2` of the external primitive
points has kernel index `M^(q/2)` in `Z[X]/(X^q+1)`. This follows
from the unit Vandermonde matrix on the first `q/2` monomials.
The principal ideal generated by `r` lies in that kernel.
Irreducibility of `X^q+1` makes its ideal index a nonzero determinant;
the determinant is divisible by `M^(q/2)`. Its columns are negacyclic
shifts of the coefficient vector of `r`. Hadamard's bound therefore
gives `||r||_2^q>=M^(q/2)`, contradicting (7).

Thus `r=0`, and `g=(X^q+1)g_1` over the integers. Its two coefficient
blocks are identical and disjoint, so

```math
\|g_1\|_2=\|g\|_2/\sqrt2,\qquad \deg g_1\le q-2.
```

This proves the next induction step. At its end,
`v=c S_(A/2)(X^2)`. At least one of recipients `0,A/2` is external,
so `M` divides `c`. Nonzero `c` would give norm at least `M`, which
contradicts the assumed norm. This proves (5).

This is an integer lattice statement over the actual composite
modulus. It does not assume the residue ring is a field.

## 3. An explicit affine lattice from the observations

Remove the first-transform twiddle from each boundary value. Let
`J` be the external recipient list and `z_j` its prescribed values.
Out-of-range residue labels are rejected before this step.

If `a=0`, check that all prescribed values are zero. If `a<=|J|`,
invert the square Vandermonde system at the first `a` recipients.
There is at most one coefficient vector modulo `M`; select its
canonical representatives and check every digit and every remaining
observation. This case needs no lattice reduction.

Suppose now that `a>|J|`, and put `s=|J|`. Write the observation
matrix as `[V W]`, where `V` is its first `s` columns. Its determinant
is a unit. Compute canonical integer lifts of

```math
H=-V^{-1}W\pmod M,
\qquad x_0=(V^{-1}z,0,\ldots,0)\pmod M.           \tag{8}
```

The following columns form an exact integer basis of (4):

```math
B=\begin{pmatrix}M I_s&H\\0&I_{a-s}\end{pmatrix}. \tag{9}
```

Indeed, their observations vanish. Conversely, the last `a-s`
coordinates of any kernel vector determine its coefficients on the
last columns; subtracting them leaves a vector supported on the first
`s` coordinates, all divisible by `M`. The complete solution set for
the prescribed observations is exactly `x_0+Lambda_(a,I)`.

All entries in (8)--(9) have `O(m)` bits. Modular inverses and the
matrix operations have polynomial bit cost, even when `M` is composite.

## 4. Exact nearest-plane recovery of the bounded input

Apply deterministic LLL reduction with parameter `3/4` to a basis of
`Lambda_(a,I)`. We use the original polynomial-time integer algorithm
of A. K. Lenstra, H. W. Lenstra Jr., and L. Lovasz,
*Factoring polynomials with rational coefficients*, Math. Ann. 261
(1982), 515--534
([primary paper](https://www.math.ucdavis.edu/~deloera/MISC/LA-BIBLIO/trunk/Lovasz/LovaszLenstraLenstrafactor.pdf),
[DOI](https://doi.org/10.1007/BF01457454)). The decoding consequence
needed here follows directly from its reduction inequalities.
Proposition 1.26, on printed page 519, gives the polynomial arithmetic
operation count and polynomial integer bit lengths for this algorithm.

Let `b_i*` be the Gram--Schmidt vectors of the reduced basis. Size
reduction and the Lovasz condition imply

```math
\|b_i^*\|_2^2\ge\tfrac12\|b_{i-1}^*\|_2^2.
```

Since `b_1*=b_1` is a nonzero lattice vector, (5) gives

```math
\min_i\|b_i^*\|_2
 \ge2^{-(a-1)/2}\lambda_1(\Lambda_{a,I})
 \ge2^{-a/2}\sqrt M
 >b\,2^{(t+A-a)/2}>b\sqrt a.                    \tag{10}
```

The last inequalities use (3), `a<=A-1`, and `2^t=A^2/2`.

Put `c=((b-1)/2,...,(b-1)/2)`. If a valid bounded input vector `x`
exists, then

```math
x-x_0\in\Lambda_{a,I},\qquad
\|(c-x_0)-(x-x_0)\|_2
 =\|c-x\|_2\le\tfrac{b-1}{2}\sqrt a
 <\tfrac12\min_i\|b_i^*\|_2.                    \tag{11}
```

Run the usual backward nearest-plane rounding on the target `c-x_0`:
for `i=a,...,1`, project the current residual onto `b_i*`, round its
coefficient to the nearest integer, and subtract that multiple of
`b_i`. Equation (11) makes every rounding exact. To see this without
an approximation theorem, compare the target with `x-x_0`. At each
step the error's component along `b_i*` has magnitude less than half
that vector's length. The higher lattice coefficients have already
been removed; lower basis vectors are orthogonal to `b_i*`. The rounded
coefficient is therefore precisely the coefficient of `x-x_0`.

Add `x_0` to the recovered lattice vector. Check that the result has
the actual digit bounds, truncated top digit, exact operand length,
prefix bits, and all observations. If no valid bounded input exists,
these checks reject. No existence assumption is made for arbitrary
boundary labels.

The center uses half-integers, and all projections and rounding can
be computed with exact rational arithmetic. LLL has polynomial bit
complexity on (9); the Gram--Schmidt rational bit lengths and the
backward rounding bit lengths are polynomial in `a` and `m`. These
parameters are polynomial in `n`, so the full entry decoder has an
absolute polynomial bit bound. The reduced kernel basis is independent
of the boundary values and may be reused, although reuse is not needed
for this complexity claim.

Once all internal first-transform inputs are recovered, the middle,
inverse, and carry settings are forced exactly as in the observable
constructor. Each accepted entry remains one; no numerical
approximation or noninteger table value is introduced.

## 5. Full written cost and constants

Use the same contiguous grouping and carry relays. With
`kappa=ceil(A/P)`, their exact common channel width is

```math
\lambda=6\kappa^2 f+2\kappa f+4\kappa c.          \tag{12}
```

The new ceiling in (3) gives `f<=2w+t+A+D`. Relative to the previous
upper bound `f<=2w+t+D`, the only additional term in `A^2 f/n` is
`A^3/n`. Uniformly under the cutoff,

```math
\frac{A^3}{n}\le\frac1{1024}.                    \tag{13}
```

For `P=2`, this is the exact estimate `2^30/2^40=2^-10`.
For `P>=3`, `A<4P^9` gives `A^3/n<64/P^13<=64/3^13<2^-10`.
Consequently the old bounds become

```math
\frac{A^2 f}{n}<2.76407+\frac1{1024},\qquad
\frac{A^2c}{n}<1.00205,\qquad
\epsilon=P/A\le\frac1{512}.
```

Substituting into (12) yields the explicit rational inequality

```math
\frac{P^2\lambda}{n}
 <6(1+\epsilon)^2(2.76407+1/1024)
  +2\epsilon(1+\epsilon)(2.76407+1/1024)
  +4\epsilon(1+\epsilon)(1.00205)<17.             \tag{14}
```

Now enumerate all boundary labels and apply the polynomial-time
decoder. Writing every bit of the complete instance costs
`n^O(1) P 2^((P-1)lambda)`, proving (1).
Since `A^3/n` tends to zero as `P` grows under the cutoff, the leading
constant (2) is unchanged. Summing the disjoint operand-length classes
and descending the divisor-prefix tree costs polynomially many such
instances, exactly as before.

## 6. Verification and scope

The companion checker implements the unit-Vandermonde affine lattice,
exact rational LLL, and nearest-plane rounding. It compares decoded
bounded inputs with complete enumeration, includes composite moduli,
checks incorrect and out-of-range observations, and compares complete
local table entries with the original bounded-input enumeration.
It also checks the new finite-parameter inequalities at ceiling
boundaries.

Run

```sh
python tools/check_lattice_boundary_decoder.py --output evidence/lattice-boundary-decoder.json
```

The [checker](../tools/check_lattice_boundary_decoder.py) and
[exact evidence](../evidence/lattice-boundary-decoder.json) record 88
complete bounded input maps, 1,720 complete input recoveries, 270 larger
digit-box controls, and 35 independently verified reduced lattice
bases. The entry decoder matches 55,902 reference assignments across
36 genuine and 72 mutated local boundaries. All genuine entries are
one. There are also 704 arbitrary observation comparisons, 88 invalid
observation rejections, 36 padding rejections, and 6,028 exact parameter
checks, including width-ceiling boundaries.

The norm proof and LLL complexity theorem establish the unbounded
claim. Finite replay supplies implementation controls. This theorem
changes the constructor and its per-entry access cost; an improved
recursive evaluator or a complete factoring exponent above one half
still requires additional work.
