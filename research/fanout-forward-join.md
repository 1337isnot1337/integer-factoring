# The source fan-out is a forward map, not an input-message product

## Result and scope

The source fan-out edge has one row per input digit vector and one
column per recipient-message vector. Its entry is one exactly when the
message vector is the forward evaluation of the input. The full
recipient map is injective on the source digit domain, so the edge
relation is functional: one message vector per input, not a dense
Cartesian product.

At `h=2` the source fan-out has `256^2 = 65,536` inputs and
`65,536 * (2^32+1)^4` input-message pairs in the full product. Forward
evaluation visits `65,536` messages, a reduction factor of
`340282367237851113631112422265381191681`. At `h=1` the factor is
`66,049`. This reproduces the source rank statement `rank(E_J)=B^h` on
the full recipient set in these finite cases.

This is a finite diagnostic for the source fan-out only. It does not
compress the later evaluator pad `V=P^2 lambda`, the multiplication or
carry edges, or the complete factoring bound. The score remains `1/2`.

## Mechanism

For the full recipient set, the source map

```math
F_J:\{0,\ldots,B-1\}^h\to R^J
```

is injective. The edge matrix `E_J` therefore has exactly one `1` in
each input row. The local sum over compatible input-message settings is
a sum over the image of `F_J`, which can be generated by evaluating
`F_J` once per input. It is not necessary to enumerate the product of
the input domain and the ambient message space.

This is the concrete content of the local-solver route in
[the half-top structure note](half-top-structure.md): count compatible
settings without visiting their whole Cartesian product. The forward
map supplies the compatible settings directly. The same observation
underlies [the hash-join identity-minor diagnostic](hash-join-identity-minor.md).

## What remains

The half-top lower bound has two terms, the local enumeration `H_Q` and
the pad term `V/r`. Forward evaluation addresses the fan-out part of the
first term. The middle and inverse gates have full output ranges, and
the pad term is untouched. A complete improvement still needs a joint
boundary compression of the later contracted tensor or a changed source
family; this note does not claim either.

The next bounded diagnostic is to measure the same forward/multiplicity
profile for a middle or inverse edge at a small source parameter, and
to test whether the pad derivation can be expressed in terms of the
functional image rather than the ambient message product.

## Reproduction

```sh
python3 tools/check_fanout_forward_join.py \
  --output evidence/fanout-forward-join.json
make verify-fanout-forward-join
```

The checker uses the source `Fanout` implementation, enumerates every
input at `h=1,2`, and asserts that the full recipient map is injective.
It does not enumerate the ambient message space.
