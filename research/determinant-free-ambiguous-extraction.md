# Factoring directly from relation rows by repeated halving

## Result and scope

A full-rank matrix of class-group relations is enough to extract a
proper factor of an odd integer with at least two distinct prime
factors. The algorithm below does not compute the relation determinant,
the class number, or an annihilator. It uses binary linear algebra,
integer row updates, and exact class-group operations.

The key input is the
[classification at discriminant `-4N`](direct-discriminant-short-norms.md):
among nonidentity ambiguous classes, at most one fails to give a proper
factor. This permits a deterministic relation-halving algorithm that
tests at most two class values per iteration. Every unsuccessful
iteration divides the relation-lattice index by two.

For an `m` by `m` relation matrix with row norm at most `H`, there
are at most `m log_2 H` such updates. All integer and class-group
costs are polynomial in the input sizes. In particular, a strictly
dominant short-word relation matrix can be used directly, without the
determinant and long exponentiations in the previous prototype.

The algorithm is complementary to the
[early annihilator extractor](polynomial-ambiguous-extraction.md), which
remains appropriate when an annihilator is supplied without relation
rows. Neither extractor solves the remaining deterministic norm-selection
problem or improves the complete factoring exponent on its own.

## 1. Half-relations describe the presented two-torsion exactly

Let `g_1,...,g_m` generate a finite abelian group `G`. Write the
group additively in this proof. Suppose the rows of an integer matrix
`R` are genuine relations and `det R != 0`. Let

$$L=\mathrm{row}_{\mathbb Z}(R),\qquad
 A=\mathbb Z^m/L.$$

The evaluation map `phi:Z^m -> G` descends to a surjection `A -> G`.
The relation lattice may be a proper sublattice of the full kernel.

For a binary row vector `w` with `wR=0 mod 2`, define

$$v_w=\frac12 wR\in\mathbb Z^m.\tag{1}$$

Its class in `A` has order at most two. The map

$$\ker(R^T\bmod2)\longrightarrow A[2],\qquad
 w\longmapsto v_w+L\tag{2}$$

is an isomorphism of binary vector spaces, where the kernel notation
identifies column vectors with the transposes of the displayed row
vectors. For injectivity, if `wR/2=zR` for an integer vector `z`,
nonsingularity implies `w=2z`, so the binary vector `w` is zero.
For surjectivity, write `2v=zR` and reduce `z` modulo two.

Consequently every `phi(v_w)` is an involution or the identity. An
unsaturated relation lattice can send all its current half-relations
to the identity. That is why a single halving pass is insufficient.

## 2. A harmless half-relation halves the lattice index

Suppose `w` is nonzero and `phi(v_w)=0`. Choose any index `j` with
`w_j=1`, and replace row `j` of `R` by `v_w`. The new row is still
a genuine relation. Moreover,

$$R_j=2v_w-\sum_{i\ne j}w_iR_i,$$

so the new row lattice is exactly `L+Z v_w`. It contains `L` with
index two. Equivalently, multilinearity of the determinant gives

$$|\det R_{\rm new}|=\frac12|\det R|.\tag{3}$$

The algorithm uses the row replacement, not a determinant calculation.
Equation (3) only proves progress and termination. Nonsingularity is
preserved at every update.

The binary dependency can be chosen by ordinary row elimination on
`R mod 2`, recording each row's coefficient mask. The first two
dependencies found are independent, since their last original row
indices are distinct.

## 3. Two evaluations suffice when only one top is rejected

Assume a test recognizes useful nonidentity involutions and rejects
at most one other nonidentity involution, denoted `tau`. Its value
need not be known in advance. At each iteration obtain the first two
independent dependencies, or the whole kernel if its dimension is
smaller than two.

For each dependency `w`, evaluate `phi(v_w)`.

- If it is useful, return it.
- If it is the identity, perform the update in Section 2.
- Otherwise it is the unique rejected top `tau`.

If both independent dependencies `w_1,w_2` give `tau`, use their
binary sum `w=w_1 xor w_2`. This is nonzero. Since XOR differs from
ordinary addition by twice an integer vector,

$$v_w-v_{w_1}-v_{w_2}\in L.$$

It follows that `phi(v_w)=tau+tau=0`. This also supplies an allowed
update, without a third class evaluation.

Only two stopping cases return no useful top:

1. The binary kernel is zero. Then `A` has odd order, so its quotient
   `G` has no nontrivial two-part.
2. The binary kernel has dimension one and its half-relation maps to
   `tau`. The Sylow two-subgroup of `A` is cyclic. Its quotient in
   `G` is cyclic as well, and the nonzero image of its unique
   involution is the unique involution in that quotient. Thus the
   two-part of `G` has no useful top.

These statements justify failure exactly for the subgroup generated by
the supplied elements. Full generation of a larger intended group is
a separate application hypothesis.

## 4. Apply the algorithm to `C_{-4N}`

For an odd `N>1`, use primitive reduced positive forms of discriminant
`-4N`. The identity is `(1,0,N)`. The ambiguous-form classification
proves the following facts without factoring `N` in the algorithm.

If `N=3 mod 4`, every nonidentity ambiguous form gives a proper
factor by the displayed gcd formulas. If `N=1 mod 4`, the only
additional rejected class is

$$(2,2,(N+1)/2).\tag{4}$$

When `N` has at least two distinct prime factors, the full class group
contains a useful ambiguous class. More specifically, its two-rank is
`omega(N)-1` in the first case and `omega(N)` in the second. Thus the
two failure cases in Section 3 cannot occur before success when the
supplied generators span the full class group.

The class-group algorithm therefore returns a proper divisor from any
nonsingular matrix of genuine relations on full generators. It needs
no saturated presentation and no exact group order. Prime powers and
partial generating sets can return no factor, with the precise subgroup
meaning stated above.

For the short-norm application, the relation rows are

$$R_i=K e_i-v_i,\qquad \|v_i\|_1\le L<K.$$

They are strictly diagonally dominant because

$$|R_{ii}|\ge K-|v_{ii}|>
 \sum_{j\ne i}|v_{ij}|.$$

Strict dominance proves nonsingularity directly. The implementation's
class-group wrapper checks this condition, so it does not need to
compute a determinant merely to validate its full-rank input contract.

## 5. Bit cost and an explicit stopping bound

Let `H_i` be the initial row's `l1` norm. Hadamard's inequality gives

$$0<|\det R|\le\prod_i H_i.$$

The implementation computes the integer bound

$$J=\sum_i\lceil\log_2 H_i\rceil\tag{5}$$

using binary bit lengths. There can be at most `J` index-halving
updates. The proof permits one final kernel pass after those updates.
For dominant short-word rows, `H_i<=K+L`, so

$$J\le m\lceil\log_2(K+L)\rceil.$$

The new row is half a sum of at most `m` old rows. If initial entries
have at most `B` bits, every entry after at most `J` updates has
`O(B+J log(m+1))` bits. Binary elimination, row addition, exact
division by two, and signed group exponentiation therefore all have
polynomial cost. No unbounded integer height is hidden in the repeated
updates. The implementation caches positive and negative generator
powers, so it does not reconstruct each power table at every pass.

With the [powered-prime parameters](powered-prime-smooth-norms.md),
`m=2^O(sqrt(b))`, `K=O(sqrt(b))`, and each reduced form has `O(b)`
bits. Every fixed polynomial in these quantities is still
`2^O(sqrt(b))`. This closes extraction and integer linear algebra at
that scale once the norm witnesses have been selected. It does not
charge a successful norm search by its output length.

## 6. Independent partial relations can already suffice

Suppose instead that `R` has `r<=m` independent rows. Put

$$L_{\rm sat}=(L\otimes\mathbb Q)\cap\mathbb Z^m.$$

The torsion subgroup of `Z^m/L` is exactly `L_sat/L`. The
half-relation map (2) remains an isomorphism onto its two-torsion.
Replacing a selected row by its half-relation multiplies every
`r` by `r` minor by one half. The positive gcd of those minors,
equal to `[L_sat:L]`, therefore halves at every allowed update.
This initial index is at most any nonzero maximal minor, and hence
at most `prod_i H_i` by Hadamard. The same explicit stopping bound
and bit-height argument apply.

Identity updates preserve the rational row span, its saturated lattice,
and the image `H=phi(L_sat)` in the class group. Thus the algorithm
finds a useful involution in `H` or certifies that `H` has none.
Its failure says nothing about elements coming from the free quotient
`Z^m/L_sat`, which has rank `f=m-r`. A partial presentation must
not be treated as an annihilator of all the generators.

There is still a useful consequence under full class-group generation.
The quotient `G/H` is generated by at most `f` elements. For finite
abelian groups, the number of generators needed by the two-part
satisfies

$$d_2(G)\le d_2(H)+d_2(G/H)\le d_2(H)+f.$$

Failure gives `d_2(H)=0` when `N=3 mod4`, and `d_2(H)<=1` when
`N=1 mod4`. The two-rank formulas in Section 4 imply in either case

$$\text{failure on independent rows of deficiency }f
 \quad\Longrightarrow\quad\omega(N)\le f+1.\tag{6}$$

In particular, `r=m-f` independent relation rows guarantee a factor
whenever `N` has at least `f+2` distinct prime factors. For semiprimes,
a proper factor can still appear before the full relation matrix is
available; no such early success is guaranteed by (6).

For rows `K e_(j_i)-v_i` with distinct designated indices `j_i` and
`||v_i||_1<K`, the minor on those designated columns is strictly
diagonally dominant. It certifies row independence without a determinant
calculation. The implementation checks the designated minor directly.
This permits a finite norm-search program to try partial relations,
skip a target that exceeds its current budget, and continue on other
targets. Every returned factor remains exact; a failed partial attempt
retains the limited meaning proved above.

## 7. Implementation and exact controls

The generic implementation is
[`relation_two_saturation.py`](../tools/relation_two_saturation.py).
It accepts arbitrary abelian-group operations and a test with at most
one rejected nonidentity involution. Its class-group wrappers check
primitive discriminants and strict diagonal dominance of either the
whole matrix or the designated minor. Initial relation identities are
verified by default. A caller may skip that repetition only after
establishing the same identities during relation construction.

Run:

```sh
python3 tools/check_relation_two_saturation.py \
  --output evidence/relation-two-saturation.json
```

The [exact checker](../tools/check_relation_two_saturation.py) passes
158 product-group controls, including a 128-step saturation chain and
an explicit XOR update from two rejected tops. Another 180 partial
presentations compare the output with an independently enumerated
torsion image. Their 218 index-halving updates are checked through
the gcd of every maximal minor. Thirty-two actual class-group fixtures
give twenty proper factors, and exercise ten paired-top updates.

The checker also verifies all 376 previously stored relation rows
for the 60-bit and 92-bit semiprimes. Both factors arise from the
first half-relation evaluated. Partial rows already suffice:

| Input bits | Full relation rows | First successful prefix | Returned factor | Group multiplications after row validation |
| --- | ---: | ---: | ---: | ---: |
| 60 | 92 | 89 | 1,000,000,007 | 281 |
| 92 | 284 | 280 | 2,147,483,647 | 1,236 |

The immediately preceding prefixes are also replayed and have no
useful top in their torsion images. Those images increase with the
rational spans of nested relation prefixes, so the recorded thresholds
are the first successful prefixes in their fixed order. The counts in
the last column omit only relation identities that the checker has
already independently verified; the evidence also records the full
cost with initial relation validation enabled.

The algorithm under test receives no determinant, group order, or
annihilator in any control. Independent integer determinants and
small group enumerations are used only to validate the fixtures and
the asserted progress. The complete output is
[`relation-two-saturation.json`](../evidence/relation-two-saturation.json).

No Lean formalization or stronger complete factoring score is claimed.
