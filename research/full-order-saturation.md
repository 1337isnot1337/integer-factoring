# Full order-saturation of cyclic relation kernels

## Scope

The [two-primary order-saturation theorem](two-primary-order-saturation.md)
uses diagonal order rows and pair rows at the `2`-adic levels. It proves that
the quotient in the relation kernel has odd order, and leaves the odd part
open. If pair rows at **every** prime level are allowed, the same localization
argument leaves no quotient at all: the order-derived lattice is the full
relation kernel. This note proves that extension and records a finite control.
It does **not** bound the cost or availability of the logs/unit data, the
smooth relation supply, or the complete factoring exponent.

## Setup and rows

Let `C_h` be cyclic of order `h`, with target logs `L_1,...,L_n` modulo `h`.
The relation kernel is

```math
K=\{x\in\mathbb Z^n:\sum_i L_i x_i\equiv0\pmod h\}.
```

Strip the common divisor: let `d=gcd(h,L_1,...,L_n)`, replace `h` by `h/d`
and `L_i` by `L_i/d`. The kernel is unchanged and now
`gcd(h,L_1,...,L_n)=1`.

For each target put

```math
g_i=\gcd(h,L_i),\qquad o_i=h/g_i,\qquad u_i=L_i/g_i.
```

Thus `L_i=g_i u_i`, `gcd(u_i,o_i)=1`, and `o_i` is the target order.

For every prime `\ell\mid h`, choose an anchor `k=k(\ell)` with
`\ell\nmid L_k`. Such an anchor exists because the logs have gcd one with
`h`. Put `j_i=v_\ell(o_i)`. The diagonal and unit-aligned pair rows are

```math
D_i=o_i e_i,
```

```math
P_{i,\ell}=u_k\,\frac{o_i}{\ell^{j_i}}e_i
          -u_i\,\frac{o_k}{\ell^{j_i}}e_k
          \qquad(i\ne k).
```

The coefficients are integers: `j_i\le v_\ell(o_k)=v_\ell(h)`, because the
anchor log is not divisible by `\ell`. Let `M` be the lattice generated by all
`D_i` and all `P_{i,\ell}`.

Rows are exact relations. For the diagonal row,
`L_i o_i=h u_i`. For the pair row, the two logarithmic contributions are both

```math
h\,\frac{u_i u_k}{\ell^{j_i}},
```

so they cancel exactly. In particular `M\subseteq K`.

## Theorem and proof

**Theorem.** `M=K`.

**Proof.** It is enough to compare the two lattices after localizing at each
prime `\ell`.

If `\ell\nmid h`, then `h` is a unit in `Z_\ell`, so `K_\ell=Z_\ell^n`.
Every `o_i` divides `h`, hence is a unit, and the diagonal rows already
generate `Z_\ell^n`. Thus `M_\ell=K_\ell`.

Now suppose `\ell\mid h`. Write `h=\ell^t h_0` with `\ell\nmid h_0`. Over
`Z_\ell`, the congruence is modulo `\ell^t`. Since `\ell\nmid L_k`, the
lattice `K_\ell` has the basis

```math
\ell^t e_k,\qquad e_i-c_i e_k\quad(i\ne k),
\qquad c_i=L_i/L_k\in Z_\ell.
```

The anchor diagonal row is

```math
D_k=o_k e_k=\ell^t\,\frac{h_0}{g_k}e_k,
```

and `h_0/g_k` is a unit, so `M_\ell` contains `\ell^t e_k`.

For `i\ne k`, set

```math
A_i=u_k\,\frac{o_i}{\ell^{j_i}}.
```

Both factors are `\ell`-adic units, so `A_i` is a unit. The ratio of the two
coefficients of `P_{i,\ell}` is

```math
\frac{u_i o_k}{u_k o_i}
=\frac{u_i}{u_k}\cdot\frac{g_i}{g_k}
=\frac{L_i}{L_k}=c_i.
```

Hence

```math
P_{i,\ell}=A_i\,(e_i-c_i e_k),
```

and, after dividing by the unit `A_i`, `M_\ell` contains every basis vector
of `K_\ell`. Therefore `M_\ell=K_\ell` for every prime `\ell`.

Since `M\subseteq K` and both are full-rank lattices, the index `[K:M]` is
finite. Its localization is one at every prime, so the index is one. ∎

## Consequences and limits

- The all-prime order-derived lattice has **no odd quotient**. The 2-primary
  theorem is the part obtainable from `2`-adic order/unit data alone; the odd
  extension uses the units `u_i` modulo the relevant odd prime powers.
- The 40-bit certificate in the two-primary note is already complete because
  its four order-derived rows happen to reach the full kernel. On another
  instance, the present rows would supply the missing odd directions as well.
- This is a lattice statement. Obtaining the logs or the unit data
  `u_i \bmod \ell^{j_i}` can cost as much as enumerating the cycle. The smooth
  pair supply and the complete factoring invoice are untouched.
- The theorem does not assert that the rows are available at low cost in the
  factoring algorithm. It removes only the odd-index obstruction from the
  order-derived row family.
