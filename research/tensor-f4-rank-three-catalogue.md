# Every extremal rank-three F4 system splits into known blocks

## Result

The [capacity theorem](tensor-orthogonal-capacity.md) gives an exact
maximum of seven nonzero columns for rank-three F4 coefficient systems
whose Gram rank equals their column rank on every subset.

A complete finite enumeration gives a stronger classification at that
maximum. Every such seven-column system is equivalent, under invertible
row operations and column permutations, to a direct sum of the known
five-column rank-two system and a two-column rank-one system. There is
no indecomposable seven-column example over F4.

This is a finite computational classification with a short exhaustive
checker. It is not asserted as an ordinary proof of the classification
over all field sizes. The rank-three capacity upper bound itself has an
ordinary proof independent of the enumeration. No new factoring bound
or crossing pressure follows from this classification.

## 1. Exhaustive normalization

Choose any three independent columns. An invertible row transformation
takes them to the standard basis of F4^3. All-subset Gram ranks are
invariant under that transformation, since each Gram matrix changes by
congruence. Column permutations also preserve the condition.

Repeated nonzero columns fail the two-column Gram condition. Thus every
rank-three seven-column system has a representative consisting of the
three standard basis columns and four distinct additional columns from
the remaining sixty nonzero vectors.

The checker first tests each possible single additional column against
all subsets of the fixed basis. Exactly forty-seven remain. Any system
containing a rejected column also contains its failing subset, so this
filter preserves completeness. It leaves

```math
\binom{47}{4}=178365
```

candidate four-column sets, from the original
`binomial(60,4)=487635` choices.

The search appends columns in increasing order. At every node it checks
all new subset Grams. A failing subset rules out all completions of that
node. The receipt counts those excluded completions and checks that
their total, plus the retained sets, is exactly 178365.

## 2. Exact finite result

There are exactly twelve retained sets in this normalization. This count
does not count GL3 orbits: it counts unordered seven-column sets that
contain the specified basis.

To identify their matroid components, connect two basis coordinates
whenever an additional column has nonzero entries in both. These are
the components generated by the fundamental circuits. In every retained
set, one component has rank one and two columns; the other has rank two
and five columns.

This decomposition is also a literal block decomposition after a row
permutation, because each column is supported in its component. The
[rank-two F4 catalogue](tensor-f4-rank-two-limit.md) shows that all
five-column rank-two systems form one unordered GL2 orbit. Any two
distinct nonzero elements of F4 form one unordered GL1 orbit: its
three nonzero scalars act transitively on the three possible pairs.
Consequently the seven-column systems form one unordered GL3 orbit,
represented by the direct sum of those two blocks.

The complete paired differential kernel on fourteen modes has dimension

```math
320\cdot10=3200.
```

The search independently obtains this same value for every retained set
from the subset-rank Hilbert formula. Different assignments of columns
to physical mode pairs can still change the crossing profiles. The
unordered orbit does not identify all physical assignments.

## 3. Replay

Run

```sh
python3 tools/tensor_f4_rank_three_catalogue.py
```

The [driver](../tools/tensor_f4_rank_three_catalogue.py) retains the
[complete receipt](../evidence/tensor-f4-rank-three-catalogue.json),
including all twelve normalized sets, branch counts, component types,
and source hashes.

Its main search uses precomputed ranks of all 4096 symmetric three-by-three
F4 matrices, together with two-column minors and three-column determinants
to update column ranks. A separate Gaussian-elimination calculation checks
all 1536 subset conditions across the twelve retained sets. The recorded
full subset count is 128 for each system, including the empty subset.
