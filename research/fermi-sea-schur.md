# Removing a complete binary block of filled fermion modes

## Result and scope

The [folded Pfaffian formula](modular-pfaffian.md) admits an exact reduction
when every label contains the same complete binary block of low modes.
Eliminating that block multiplies the remaining profile by one scalar
polynomial. It does not create a new space of piece tensors.

This gives a precise answer for one proposed use of long, nearly filled
labels. Under the separation condition below, the final pieces are copies
of the lower-energy pieces and have exactly the same ranks. The argument
concerns this label construction. It is not a lower bound on other modular
crossing families or on factoring algorithms, and establishes no exponent
above `1/2`.

The operators and crossing identity remain Claude (Anthropic)'s Appendix B
at
[`anthropics/formal-math@16a5ce41304fcdaea4e0be7c132e1c361dc26da5`](https://github.com/anthropics/formal-math/tree/16a5ce41304fcdaea4e0be7c132e1c361dc26da5/eth).
The quotient and the folded matrix used here are proved in the
[modular construction](past-half-pieces.md) and
[Pfaffian evaluation note](modular-pfaffian.md). The block elimination below
is a new ordinary argument, without Lean formalization.

## 1. The lift and its exact profile

Let `K=2^a` for an integer `a>=0`. Every low label is a partition `mu`
of the same weight `h0>=1`, has the same number `r>=1` of parts, and consists
of distinct positive odd parts less than `2K`. Define

```math
\Phi_K(\mu)=\{1,3,\ldots,2K-1\}
             \mathbin\cup\{2K+t:t\in\mu\}.
\tag{1}
```

The union is disjoint. Every lifted label is regular in characteristic two,
has `K+r` parts, and has weight

```math
h=K^2+2Kr+h_0.
\tag{2}
```

For a label tuple `x,y,u,v`, write its Laurent profile as
`A_low(z)=sum_s A_s(x,y,u,v)z^s`, and write `A_lift(z)` for the
profile on the four lifted labels. Then

```math
\boxed{
A_{\rm lift}(z)
=(z^{-2K}+1+z^{2K})^{K+2r}A_{\rm low}(z).
}
\tag{3}
```

Equivalently, for the ordinary polynomials returned by the implementation,

```math
P_{\rm lift}(z)
=D_K(z)^{K+2r}P_{\rm low}(z),\qquad
D_K(z)=1+z^{2K}+z^{4K},
\tag{4}
```

where `P_lift=z^(2h) A_lift` and `P_low=z^(2h0) A_low`.
The multiplier is common to every four-label tuple. At `z=1` it is one,
so it preserves the crossing sum.

## 2. Canonical form of the common core

Work temporarily over the rational-function field `F_2(z)`.
The final identity (4) is polynomial. Index the core modes by
`t_i=2i+1`, `0<=i<K`. Set

```math
w=z^2,\quad q=1+w,\quad r_z=1+z,
\qquad T=w^K=z^{2K},\quad Q=q^K=1+T,
\quad D=1+T+T^2.
```

The equality `q^K=1+w^K` uses that `K` is a power of two.
Introduce the following `K` by `K` matrices:

```math
\begin{aligned}
W&=\operatorname{diag}(w^i),&
V&=\operatorname{diag}(q^i),\\
P_{ij}&=[i\subset j],&
R_{ij}&=[j=K-1-i],\\
J_{ij}&=[i\mathbin{\rm AND}j=0],&
H_{ij}&=w^{i\mathbin{\rm AND}j},\qquad
O_{ij}=w^{i\mathbin{\rm OR}j}.
\end{aligned}
\tag{5}
```

Here `i subset j` is containment of binary one-bits. The Boolean zeta
matrix satisfies `P^2=I`, the complement permutation satisfies `R^2=I`,
and `J=PR`. All matrices that are inverted below are invertible over
`F_2(z)`.

The six folded blocks of the common core, in order `U,A,B,Y`, are

```math
UA=z r_z O,\quad AY=r_z H,\quad AB=zWP,\quad
UB=r_zP^TV,\quad BY=z r_z VJW,\quad UY=zW.
\tag{6}
```

These identities are direct substitutions of `t_i=2i+1` into the
folded matrix.

Each matrix in (5) is a tensor product over the `a` binary digits.
For one digit with parameter `b=w^(2^j)`, the matrices are

```math
P_b=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
R_b=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad
W_b=\operatorname{diag}(1,b),\quad
V_b=\operatorname{diag}(1,1+b),
```

```math
H_b=\begin{pmatrix}1&1\\1&b\end{pmatrix},\qquad
O_b=\begin{pmatrix}1&b\\b&b\end{pmatrix}.
```

Multiplying these two-by-two matrices and then taking tensor products gives

```math
\begin{aligned}
PJ&=R,\\
O^{-1}HW^{-1}&=w^{-(K-1)}R,\\
O^{-1}WPV^{-1}P^T&=q^{-(K-1)}R.
\end{aligned}
\tag{7}
```

Let `C0` denote the full common-core matrix. Apply the block-diagonal
congruence

```math
X=\operatorname{diag}
\left(I,(zr_zO)^{-1},(r_zP^TV)^{-1},(zW)^{-1}\right).
```

Equations (6)--(7) give

```math
C=X^TC_0X=
\begin{pmatrix}
0&I&I&I\\
I&0&Q^{-1}R&T^{-1}R\\
I&Q^{-1}R&0&R\\
I&T^{-1}R&R&0
\end{pmatrix}.
\tag{8}
```

All its blocks lie in the commutative algebra generated by `I,R`,
with relation `R^2=I`. Put `g=D/(TQ)`. Direct multiplication gives

```math
C^{-1}=g^{-1}
\begin{pmatrix}
0&I&T^{-1}I&Q^{-1}I\\
I&0&R&R\\
T^{-1}I&R&0&R\\
Q^{-1}I&R&R&0
\end{pmatrix}.
\tag{9}
```

In particular the common core is nonsingular over `F_2(z)`.

## 3. Eliminate the core and retain the same low kernel

First include every possible active mode `2K+t_i`, and restrict to the
chosen active modes only after the calculation. Adding `2K` changes one
binary bit, so each core-to-active block follows directly from (6).
Use the same congruence `X` on the active indices. The transformed
core-to-active and active-to-active blocks are respectively

```math
B=
\begin{pmatrix}
0&TI&0&0\\
TI&0&Q^{-1}R&T^{-1}R\\
I&0&0&TR\\
0&T^{-1}R&QR&0
\end{pmatrix},
\tag{10}
```

```math
E=
\begin{pmatrix}
0&TI&QI&TI\\
TI&0&(T/Q)R&R\\
QI&(T/Q)R&0&0\\
TI&R&0&0
\end{pmatrix}.
\tag{11}
```

Using (9), ordinary four-by-four block multiplication gives the exact
Schur identity

```math
E+B^TC^{-1}B=D C.
\tag{12}
```

For completeness, the six upper off-diagonal blocks of its left side
are `DI,DI,DI,(D/Q)R,(D/T)R,DR`, in pair order
`UA,UB,UY,AB,AY,BY`; all diagonal blocks are zero.
The plus sign is the Schur-complement minus sign in characteristic two.

Undo the active congruence while retaining the normalized core basis:

```math
B_0=BX^{-1},\qquad E_0=X^{-T}EX^{-1}.
```

Equation (12) becomes `E0+B0^T C^-1 B0=D C0`. Thus eliminating the
common core leaves **`D` times the original low folded matrix**.
Only now restrict the active indices, which are back in the original
mode basis. Keep the desired columns of `B0` and the corresponding
principal submatrix of `E0`. This restriction commutes with the Schur
operation, so the result holds for the selected parts of each of the
four labels, not only for a full active cube. The congruence `X` mixes
mode indices and is not itself restricted to the selected subsets.

The required restriction `t<2K` ensures that every active mode `2K+t`
has exactly this one additional binary bit. The calculation does not
claim the same reduction for modes beyond that next block.

## 4. Core Pfaffian and normalization

Eliminate the `U,Y` identity blocks in (8). The remaining `A,B`
block is `gR`, with zero diagonal blocks. Hence

```math
\operatorname{Pf}C=\det(gR)=g^K.
```

The determinants of the three nonidentity blocks in `X^-1` multiply
to `(TQ)^K`. To check this, the binary factors above give

```math
\det O=(wq)^{K(K-1)/2},\qquad
\det W=w^{K(K-1)/2},\qquad
\det V=q^{K(K-1)/2},\qquad \det P=1.
```

Together with (6), their product is `(wq)^(K^2)=(TQ)^K`.
Since `Pf(X^TC0X)=det(X)Pf(C0)`, it follows that

```math
\operatorname{Pf}C_0=D^K
=1+z^{2K^2}+z^{4K^2}.
\tag{13}
```

There are `4r` active vertices for four labels of cardinality `r`.
The Pfaffian Schur identity, (12), and (13) now give

```math
\operatorname{Pf}M_{\rm lift}
=\operatorname{Pf}C_0\,
  \operatorname{Pf}(D M_{\rm low})
=D^{K+2r}\operatorname{Pf}M_{\rm low}.
```

The Pfaffian Schur identity follows by a block triangular congruence
with determinant one, which zeros the core-to-active block. It is valid
over `F_2(z)` because the core is nonsingular. Both sides displayed here
are polynomials, so equality holds in `F_2[z]` as well.
This proves (4). Dividing by `z^(2h)` and using (2) proves (3).

## 5. What this says about ranks

Because `D^(K+2r)` has constant coefficient one, convolution by it
preserves the linear span of all piece tensors. One inclusion is clear
from (4). For the other, recover the coefficients of `P_low` successively
from degree zero upward; the coefficient at the current degree enters
with coefficient one, and every other term is already recovered.

**Span equality is not rank equality.** A linear combination can have a
different matrix rank from each of its summands. When coefficient copies
overlap, (4) alone gives no equality of individual piece ranks.

There is a useful exact separated case. If

```math
K>2h_0,
\tag{14}
```

all nonzero exponents of `D^(K+2r)` are multiples of `2K`, while
`deg P_low<=4h0<2K`. Shifted copies of `P_low` therefore cannot overlap.
Every nonzero lifted piece tensor is exactly one low piece tensor,
and every low piece occurs because the multiplier's constant coefficient
is one. In this case the maximum row rank, maximum column rank, maximum
rank product, and the set of attained rank pairs are unchanged, except
for possible additional zero pieces.

This rules out obtaining a better rank profile by adding this sufficiently
large complete background. It does not rule out using a useful scalar
combination of low pieces in the overlap regime, or a label set that is
not of the form (1). Those remain separate questions about actual ranks.

## 6. Exact checks

Run:

```sh
python3 tools/check_fermi_sea_schur.py
```

The checker compares the two sides of (4) using the independently
implemented folded Pfaffian. It includes a small core, an example with
overlapping coefficient supports, and an example satisfying (14).
In the separated example it also checks the attained row/column rank
pairs. It records actual overlap in the other example, rather than
mistaking span preservation for rank preservation.

The output is [fermi-sea-schur.json](../evidence/fermi-sea-schur.json).
These finite checks verify transcription and normalization of the new
identity. Its all-parameter proof is the block calculation above.
