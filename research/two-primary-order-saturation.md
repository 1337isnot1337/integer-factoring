# Two-primary saturation from target orders

## Scope

This note isolates the `2`-primary part of a cyclic relation lattice. The
main result is a lattice theorem: order-derived rows always 2-saturate the
relation kernel of a cyclic group. A full-prime extension, using the same
local argument at every prime, generates the entire kernel when the units
modulo the relevant prime powers are available. It does **not** bound the
cost of obtaining those orders or units, or the complete factoring exponent.

The motivating certificate is the 40-bit mixed-pair cycle in
[mixed-pair-gap-cycle.md](mixed-pair-gap-cycle.md). There the window-`2`
pair rows have index `16h` in the full kernel, and a previous window-`3`
repair used four smooth exponent-`3` rows. The construction below repairs
the same `2`-primary defect using only target orders.

## Setup

Let `C_h` be cyclic of even order `h`, and let target classes have logs
`L_1,...,L_n` modulo `h`. The relation lattice is

`K = {x in Z^n : sum_i L_i x_i = 0 mod h}`.

Let `d = gcd(h, L_1,...,L_n)`, put `h' = h/d` and `L'_i = L_i/d`. The
congruence is unchanged, so `K` is the kernel for `(h', L')`, and
`gcd(h', L'_1,...,L'_n) = 1`.

For each target put

`g_i = gcd(h', L'_i)`, `o_i = h'/g_i`, `u_i = L'_i/g_i`.

Thus `o_i` is the order of the target in `C_{h'}`, `L'_i = g_i u_i`, and
`gcd(u_i,o_i) = 1`. Let `t = v_2(h')` and `level_i = v_2(o_i)`. If `h'` is
even, primitivity gives some odd `L'_i`, hence some `level_i = t`; call these
the **top targets**.

## Order-derived rows

The diagonal row is

`D_i = o_i e_i`.

It lies in `K`, since `L'_i o_i = h' u_i`.

For a non-top target `i` with `1 <= level_i < t`, choose a top target `k`
and set `j = level_i`. Choose integers `r,s` with

`r = u_k mod 2^j`, `s = u_i mod 2^j`.

The row

`P_{i,k,j} = r (o_i/2^j) e_i - s (o_k/2^j) e_k`

lies in `K`, because

`L' . P = (h'/2^j)(r u_i - s u_k) = 0 mod h'`.

For the top targets, connect a chosen top anchor `k_0` to every other top
target `k` by the same formula with `j=t`. If `h'` is odd, use only the
diagonal rows.

## The 2-saturation theorem

**Theorem.** Let `M` be the lattice generated by the rows above. Then
`M` is contained in `K`, and `K/M` has odd order. Equivalently, `M` is
`2`-saturated in `K`.

**Proof.** Containment is the calculation above. It remains to show that
`M` and `K` have the same `2`-adic closure.

Localize at `2` and write `h' = 2^t h_odd` with `h_odd` odd. If `h'` is odd,
then `h'` is a unit in `Z_2`, so the relation imposes no constraint over
`Z_2`: `K_2 = Z_2^n`. The diagonal rows have odd coefficients and generate
`Z_2^n`, so `M_2 = K_2`.

Assume `h'` is even. Over `Z_2`, the congruence `sum L'_i x_i = 0 mod h'` is
the same as `sum L'_i x_i = 0 mod 2^t`, because `h_odd` is a unit. Choose a
top anchor `k_0`, so `L'_{k_0}` is odd. Put `c_i = L'_i/L'_{k_0}` in
`Z_2`. The lattice `K_2` has basis

`2^t e_{k_0}`, and `e_i - c_i e_{k_0}` for `i != k_0`.

Indeed, the kernel of the projection to the coordinates `i != k_0` is
exactly `2^t e_{k_0}`, and the displayed vectors solve the congruence.

The anchor diagonal row is `o_{k_0} e_{k_0} = 2^t * (odd unit) e_{k_0}`,
so `M_2` contains `2^t e_{k_0}`. For `i != k_0`, we produce
`e_i - c_i e_{k_0}`:

- If `level_i = 0`, the diagonal row `o_i e_i` has odd coefficient and gives
  `e_i`; also `v_2(c_i) >= t`, so `c_i e_{k_0}` is a multiple of
  `2^t e_{k_0}`. Thus `e_i - c_i e_{k_0}` is in `M_2`.
- If `1 <= level_i < t`, use the pair row `P_{i,k_0,level_i}`. Its
  coefficient at `e_i` is odd, so over `Z_2` we may normalize the row by that
  unit. Write the normalized other coefficient as `S/R`, where
  `R = r(o_i/2^j)` and `S = s(o_{k_0}/2^j)`. A direct calculation gives
  `S/R - c_i = (o_{k_0}/o_i)(s/r - u_i/u_{k_0})`.
  The congruences `r = u_{k_0} mod 2^j`, `s = u_i mod 2^j` make the second
  factor divisible by `2^j`, while `o_{k_0}/o_i` has valuation `t-j`. Hence
  `S/R - c_i` is divisible by `2^t`. The difference is therefore a multiple
  of `2^t e_{k_0}`, which is already in `M_2`; hence so is
  `e_i - c_i e_{k_0}`.
- If `level_i = t` and `i` is another top target, the same argument with
  `j=t` gives `S/R - c_i` divisible by `2^t`.

Thus `K_2` is contained in `M_2`. The reverse containment follows from
`M` contained in `K`. Therefore `M_2 = K_2`, so the index `[K:M]` has no
factor `2`, i.e. it is odd. ∎

## Full-prime extension

The same localization works at every prime. Keep the normalization
`gcd(h',L'_1,...,L'_n)=1`, and for each prime `l | h'` choose an anchor
`k(l)` with `l` not dividing `L'_{k(l)}`. Such an anchor exists by
primitivity, and its level `v_l(o_{k(l)})` is maximal. Put `j_i=v_l(o_i)`.
Adjoin, in addition to the diagonal rows `D_i=o_i e_i`, the pair rows

`P_{i,l} = u_{k(l)} (o_i/l^{j_i}) e_i
          - u_i (h'/(l^{j_i} g_{k(l)})) e_{k(l)}`

for every `i != k(l)`. The row is integral because the anchor has maximal
`l`-level, and it lies in `K` by the same calculation as before.

**Theorem (full-prime form).** The diagonal and all `P_{i,l}` rows generate
`K`, not merely its `2`-primary part.

**Proof.** Localize at `l`. Since `h' = l^t h_l` with `h_l` a unit in `Z_l`,
the relation is `sum L'_i x_i = 0 mod l^t`. The anchor log is a unit, so
`K_l` has basis `l^t e_{k(l)}` and `e_i-c_i e_{k(l)}`, where
`c_i=L'_i/L'_{k(l)}`. The diagonal row `D_{k(l)}` is `l^t` times a unit, so
it supplies `l^t e_{k(l)}`. For `i != k(l)`, the coefficient of `e_i` in
`P_{i,l}` is a unit, and the row is a unit multiple of `e_i-c_i e_{k(l)}`
over `Z_l`. Hence `M_l=K_l` for every `l|h'`; for primes not dividing `h'`,
`h'` is a unit and the diagonal rows already generate `Z_l^n`. Therefore
`M=K`. ∎

This extension is the all-prime version recorded by Worker 2 in
[Discussion #51](https://github.com/1337isnot1337/integer-factoring/discussions/51#discussioncomment-19429751).
The `2`-primary theorem is the cheaper special case: it needs only `2`-adic
orders/units, while the full-prime rows need the units at every odd prime
dividing `h'`, in practice the full logs.

## Consequences and limits

- If `M_0` is any other relation lattice contained in `K` (for example the
  window-`2` smooth pair rows), then `K/(M_0+M)` is a quotient of `K/M`, so
  adding the order-derived rows kills the entire `2`-primary part of the
  index of `M_0`. Only an odd quotient can remain.
- If the odd quotient is already trivial, as in the 40-bit certificate
  below, then `M_0 + M = K`: no further smooth window is needed.
- The construction assumes the logs or, for `v_2(h')>1`, the units `u_i`
  modulo the relevant `2`-powers. When `v_2(h')=1`, all units are odd and the
  rows use only the orders: `P_{i,k,1} = (o_i/2)e_i - (o_k/2)e_k`. For higher
  `2`-adic valuation the unit alignment is additional data.
- Without the full-prime units, the odd part of `K/M_0` is untouched. With
  the full-prime rows it is also removed, but only because the full logs are
  supplied; this is a lattice closure, not a cheap odd-quotient search.
- The cost of obtaining the orders/units is not addressed. In particular,
  this mechanism does not by itself improve the complete bound.

## The 40-bit certificate

For the cycle in [mixed-pair-gap-cycle.md](mixed-pair-gap-cycle.md),
`h = 198850 = 2*99425`, so `v_2(h)=1`. The window-`2` pair rows have index
`16h` in `K`. The order-derived repair is:

- odd-order targets `1289` and `25169`, both order `97`:
  diagonal rows lower `16h -> 8h -> 4h`;
- even-order half rows
  `99425 e_5 - 41 e_43987` and `99425 e_5 - 97 e_96749`:
  lower `4h -> 2h -> h`.

Thus the window-`2` rows plus these four order-derived rows generate the
full kernel. No exponent-`3` smooth hit is used. Replacing the cycle
generator `5` by `7` gives the same period, the same window-`2` index `16h`,
and the same four rows. The exact certificates are in
`tools/check_mixed_pair_gap_cycle.py` and its receipt.

## Verification

The theorem is proved above; the following are independent finite checks.

- `tools/check_two_primary_order_saturation.py` exhaustively enumerates
  `130176` small cyclic cases for
  `(h,n) = (8,4),(16,3),(8,5),(12,4),(24,3),(36,3),(20,3)`.
  It verifies that every constructed lattice lies in `K` and that `K/M` has
  odd order. For the full-prime extension it also verifies that the
  diagonal-plus-all-prime rows equal `K` in every case. Evidence:
  `evidence/two-primary-order-saturation.json`.
- `make verify-two-primary-order-saturation` runs that checker.
- `make verify-mixed-pair-gap-cycle` checks the 40-bit rows, both cycle
  generators, and the smooth/order-derived repair certificates.
