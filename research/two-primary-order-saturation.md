# Two-primary saturation from target orders

## Scope

This note isolates the `2`-primary part of a cyclic relation lattice. The
main statement is a **conjecture**, supported by exact small-case checks: the
order-derived rows below appear to 2-saturate the relation kernel of a cyclic
group. The note proves containment and a modulo-`2` partial result, and states
the missing `2`-adic lifting step. It does **not** bound the odd part of the
index, the cost of obtaining the orders, or the complete factoring exponent.

The motivating certificate is the 40-bit mixed-pair cycle in
[mixed-pair-gap-cycle.md](mixed-pair-gap-cycle.md). There the window-`2`
pair rows have index `16h` in the full kernel, and a previous window-`3`
repair used four smooth exponent-`3` rows. The construction below repairs
the same `2`-primary defect using only target orders.

## Setup

Let `C_h` be cyclic of even order `h`, and let target classes have logs
`L_1,...,L_n` modulo `h`. The relation lattice is

`K = {x in Z^n : sum_i L_i x_i = 0 mod h}`.

Let `d = gcd(h, L_1,...,L_n)`, put `h' = h/d` and `L'_i = L_i/d`. The
congruence is unchanged, so `K` is the kernel for `(h', L')`, and
`gcd(h', L'_1,...,L'_n) = 1`.

For each target put

`g_i = gcd(h', L'_i)`, `o_i = h'/g_i`, `u_i = L'_i/g_i`.

Thus `o_i` is the order of the target in `C_{h'}`, `L'_i = g_i u_i`, and
`gcd(u_i,o_i) = 1`. Let `t = v_2(h')` and `level_i = v_2(o_i)`. If `h'` is
even, primitivity gives some odd `L'_i`, hence some `level_i = t`; call these
the **top targets**.

## Order-derived rows

The diagonal row is

`D_i = o_i e_i`.

It lies in `K`, since `L'_i o_i = h' u_i`.

For a non-top target `i` with `1 <= level_i < t`, choose a top target `k`
and set `j = level_i`. Choose integers `a,b` with

`a = u_k mod 2^j`, `b = u_i mod 2^j`.

The row

`P_{i,k,j} = a (o_i/2^j) e_i - b (o_k/2^j) e_k`

lies in `K`, because

`L' . P = (h'/2^j)(a u_i - b u_k) = 0 mod h'`.

For the top targets, connect a chosen top anchor `k_0` to every other top
target `k` by the same formula with `j=t`. If `h'` is odd, use only the
diagonal rows; their index quotient is odd.

## The 2-saturation conjecture and partial result

**Conjecture.** Let `L` be the lattice generated by the rows above. Then
`L` is contained in `K`, and `K/L` has odd order. Equivalently, `L` is
`2`-saturated in `K`.

**Proved part: containment.** Every generated row lies in `K`.

**Proved part: modulo-`2` agreement.** Reduce the rows modulo `2`. A
diagonal row `o_i e_i` is nonzero exactly when `level_i = 0`, and then it
gives `e_i`. For a pair row at level `j`, the coefficient of `e_i` has the
parity of `o_i/2^j`, nonzero exactly when `level_i = j`; the same holds for
`k`. For a non-top target `i`, the anchor `k` has `level_k = t > j`, so the
pair row is congruent to `e_i` modulo `2`. For the top targets, the
top-level pair rows give `e_k + e_{k_0}`; their modulo-`2` span is the
even-sum subspace on the top coordinates (or the single condition
`x_{k_0}=0` if there is a unique top target).

The reduction of `K` modulo `2` is described by reducing
`sum_i L'_i x_i = 0 mod h'` modulo `2`. The coefficient `L'_i` is odd
exactly for the top targets and even otherwise, so the same even-sum
condition holds. Hence the two lattices have the same image in `F_2^n`, or
equivalently `K+2Z^n = L+2Z^n`.

**Missing step.** The last equality does **not** by itself imply
`K = L + 2K`: the kernel `K` need not be primitive, so an even vector in
`K` need not have half in `K`. The conjecture is that the pair rows at the
higher `2`-adic levels supply the lifting, i.e. a `2`-adic Smith-normal-form
or Euclidean-algorithm argument proves `K = L + 2K`. Such an argument would
also show `K/L` odd, since a finite abelian group with `Q=2Q` has odd order.

## Consequences and limits

- If the conjecture holds and `L_0` is any other relation lattice contained
  in `K` (for example the window-`2` smooth pair rows), then `K/(L_0+L)` is
  a quotient of `K/L`, so adding the order-derived rows kills the entire
  `2`-primary part of the index of `L_0`. Only an odd quotient can remain.
- If the odd quotient is already trivial, as in the 40-bit certificate
  below, then `L_0 + L = K`: no further smooth window is needed.
- The construction assumes the logs or, for `v_2(h')>1`, the units `u_i`
  modulo the relevant `2`-powers. When `v_2(h')=1`, all units are odd and the
  rows use only the orders: `P_{i,k,1} = (o_i/2)e_i - (o_k/2)e_k`. For higher
  `2`-adic valuation the unit alignment is additional data.
- The odd part of `K/L_0` is untouched. A complete factoring route still
  needs smooth relations for that odd quotient, or another argument that it
  is trivial.
- The cost of obtaining the orders/units is not addressed. In particular,
  this mechanism does not by itself improve the complete bound.

## The 40-bit certificate

For the cycle in [mixed-pair-gap-cycle.md](mixed-pair-gap-cycle.md),
`h = 198850 = 2*99425`, so `v_2(h)=1`. The window-`2` pair rows have index
`16h` in `K`. The order-derived repair is:

- odd-order targets `1289` and `25169`, both order `97`:
  diagonal rows lower `16h -> 8h -> 4h`;
- even-order half rows
  `99425 e_5 - 41 e_43987` and `99425 e_5 - 97 e_96749`:
  lower `4h -> 2h -> h`.

Thus the window-`2` rows plus these four order-derived rows generate the
full kernel. No exponent-`3` smooth hit is used. Replacing the cycle
generator `5` by `7` gives the same period, the same window-`2` index `16h`,
and the same four rows. The exact certificates are in
`tools/check_mixed_pair_gap_cycle.py` and its receipt.

## Verification

The containment and modulo-`2` agreement are proved above; the full
`2`-saturation statement remains conjectural. The following are independent
finite checks.

- `tools/check_two_primary_order_saturation.py` exhaustively enumerates
  `130176` small cyclic cases for
  `(h,n) = (8,4),(16,3),(8,5),(12,4),(24,3),(36,3),(20,3)`.
  It verifies that every constructed lattice lies in `K` and that `K/L` has
  odd order. Evidence: `evidence/two-primary-order-saturation.json`.
  A further `20000` random cases with `h` up to `512` and `n` up to `8` found
  no failure in an uncommitted diagnostic.
- `make verify-two-primary-order-saturation` runs that checker.
- `make verify-mixed-pair-gap-cycle` checks the 40-bit rows, both cycle
  generators, and the smooth/order-derived repair certificates.

   faster than the extra smooth pair search.
